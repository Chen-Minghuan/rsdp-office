## 1. 尽早执行的能力验证

RECOG-002 先做少量真实样本能力验证，与最小保存闭环并行；不等待复杂编辑全部完成后才接通识别。
固定服务/模型版本、请求参数、PDF 渲染/预处理、原图哈希与标注后运行。模型选择以这次结果为依据，不预先声称任何服务已具备精确轮廓能力。

## 2. 最小样本集合

| 编号 | 输入 | 覆盖内容 | 门槛类别 |
| --- | --- | --- | --- |
| PNG-RECT | 清晰矩形，至少两条独立实际参考长度 | 净边界、校准与第二参考长度核对 | 自动质量 + 手工完成 |
| PNG-L | 清晰 L 形 | 凹角、面积、自由/正交边长编辑 | 自动质量 + 手工完成 |
| PNG-MULTI | 多房间，至少一个未命名房间，存在墙厚 | 漏/误识别、相对位置、墙厚不报裂缝 | 自动质量 + 手工完成 |
| PDF-VECTOR | 至少两页且内容不同的矢量 PDF | 页选择、选定页渲染、页坐标一致 | 自动质量 + 手工完成 |
| PDF-SCAN | 扫描型 PDF，可靠实际长度 | 扫描页轮廓及校准 | 自动质量 + 手工完成 |
| PNG-UNKNOWN | 无可靠尺寸或模糊图 | 比例未知、部分结果/无候选、人工空稿入口 | 失败/人工路径，不混入自动质量达标分母 |

清晰样本：标准底图短边至少 1200px，主边界线可人工辨认且约 2px 以上；不为达标临时换成有利图片。
每份样本由人工按 INNER_WALL_FACE 标注外环/孔洞、明确房间清单、未命名标记和墙/柱依据；另一人复核或记录用户确认。
标注前冻结图像方向、裁剪/渲染尺寸和对应变换。标注文件未就绪的样本不能宣布已验收。
现有仓库原型截图不默认视为真实原图/金标；本轮未执行真实识别，样本清单示例也不是样本证据。

## 3. 自动识别质量：在人工作任何修正前测量

保存服务原始 JSON、标准底图及未经修改的候选轮廓。校准可用于评价单位转换，但不得先修轮廓再测自动准确率。
匹配：候选与金标按最大总 IoU 一对一匹配，只允许 IoU≥0.5 的配对；未匹配金标为漏检，未匹配候选为误检。
同一房间被拆成多个候选或多个房间合成一个，按一对一规则计漏/误检，不通过合并人工结果美化原始指标。

| 指标 | 清晰五类样本的首期门槛 | 记录方式 |
| --- | --- | --- |
| 房间召回率 | 每样本及总体 ≥0.90 | TP/(TP+FN)，同时记录具体漏检空间 |
| 房间精确率 | 每样本及总体 ≥0.90 | TP/(TP+FP)，同时记录误检轮廓 |
| 轮廓 IoU | 每个匹配空间 ≥0.90 | 按净边界/孔洞区域计算 |
| 双向边界距离 P95 | 每个匹配空间 ≤3标准底图px | 边界按 1px 弧长采样，双向点到对方线段距离合并 |
| 双向边界距离最大值 | 每个匹配空间 ≤10标准底图px | 防止平均值掩盖局部凹角偏差 |
| L 形与未命名空间 | 指定对象必须检出，不能矩形化/跳过 | 单独硬门槛，不用总体均值抵消 |
| 页目标一致性 | 100% 来自选定页，无其他页对象 | 根据来源 pageId/底图与原始输出核对 |
| 已有名称/用途 | 分别报告准确率与未知数，不作为几何召回替代 | 未命名金标不要求模型造出名称 |

按标准底图 px 测量，因此必须固定渲染尺寸；不能临时降 DPI 使边界误差数字变小。
有可靠比例时另外报告毫米误差，不把这些 px 门槛包装成施工精度。
未知/模糊样本报告同样的原始指标，但作为受限输入/降级能力展示，不影响清晰样本的分母定义。
真实图纸不符合上述清晰条件时另建样本类别和门槛；在运行前记录，不事后修改已有门槛让失败结果通过。

## 4. 人工修正后的正确性与工作量

人工阶段记录每个补画、删除误检、命名、拖边/顶点、尺寸提交与校准命令及耗时。
基线工作量从候选结果已展示开始计时；上传/网络等待单列，校准命令也单列。
每样本报告：新增/排除房间数、几何修正命令数、每房间修正时间、总完成时间、撤销次数和失败原因；报告中位数与最大值，小样本不推断整体用户效率。

手工完成门槛：

- 金标设计房间全部对应，误检全部有排除原因；人工补画记录为 MANUAL，不能回填成模型检出。
- 净边界已核对，匹配轮廓 IoU≥0.95、P95≤2px；有效性/父子/共边/障碍符合附件 A。
- 独立参考长度的校准核验误差 ≤max(20mm, 参考长度×1%)；没有第二参考长度时标为未覆盖该核验。
- 确定性软件编辑例子 6m×4m→8m×4m，尺寸误差≤1mm、面积误差≤0.01㎡；这是计算能力标准，不能代替真实轮廓测量。
- 保存恢复/确认/返回修改失效全部通过，来源轮廓和原始服务输出未被覆盖。

工作量作为独立交付结果，首轮先测基线，不编造可用性已达标；若清晰样本普遍需要重画全部房间，自动识别不能因手工完成而标为通过。
自动质量未达标但人工链路正确时，分别记“自动识别未验收”和“人工编辑闭环通过”，不合并成 PDF/PNG 识别已验收。

## 5. 失败、无候选与空稿

选定页面处理成功但识别失败、无候选或服务不可用时，允许 `initializationMode=EMPTY_PAGE` 创建空设计稿：保留 pageId/底图，sourceSceneId 为 null，附带失败 runId（如有）。
用户可校准、人工描绘、保存和确认；最终来源为人工，失败识别记录仍保留。
空稿创建不依赖 analysisId，接口与 schema 见 [附件 B](api-storage-contract.md)。空场景可保存，至少一个纳入设计且有效的空间才允许整体确认。
页面本身无法渲染时需先解决页面处理错误，不伪造底图或坐标。
