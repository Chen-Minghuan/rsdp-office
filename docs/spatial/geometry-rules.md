# Spatial 附件 A：房间边界与几何操作规则 V1.0

更新日期：2026-10-14。目标规则，尚未实现/验收；软件阈值不是建筑行业标准。
关联：[主架构](../../Spatial_Canvas_Engine_空间解析编辑与无限画布系统架构设计_V1.1.md)、[数据协议](../../Spatial_Scene_数据协议规范_V1.0.md)、[失效规则](confirmation-rules.md)。

## 1. 房间轮廓的语义

`boundaryBasis=INNER_WALL_FACE`：建筑房间的外环沿墙内侧，表示室内地面区域，不是墙中心线，也不是建筑面积边界。
识别无法确定墙内侧时保留候选轮廓，标记 `boundaryBasis=UNRESOLVED` 并产生阻止确认的问题；人工核对后才设置已解析的边界依据。
`FUNCTION_ZONE` 使用 `boundaryBasis=FUNCTIONAL_DIVISION`，表示父房间内的功能划分，必须有 `parentSpaceId`。

墙体是独立对象，不要求相邻房间多边形直接接触。墙内侧之间相隔 120mm 的两个房间可合法相邻，不能以间隔非零判定裂缝。
有墙的邻接用 `WALL_SEPARATED` 关系记录双方空间和 `wallId`；墙厚未知时只提示待核对，不猜测共享边界。
只有明确登记为 `SHARED_PARTITION` 的无墙功能分区，才检查指定边段的共边连续性；未登记的间隙不自动报裂缝。
关系由用户确认或可靠来源建立，视觉模型的邻接猜测先作为待核对线索。

同级建筑房间室内区域不允许超容差重叠。功能分区应在父空间内；父子包含关系不算同级重叠。
不同语义的功能分区允许重叠时须记录显式用途规则，首期默认同一父空间、同一排版层的功能分区不重叠。

## 2. 面积与障碍

`boundaryAreaM2` 为外环扣除孔洞的面积。孔洞用于天井、永久空洞和已表示在轮廓内的柱占地。
`areaM2` 为净地面面积：从上述区域再扣除永久实心柱/井等 `excludesFloorArea=true` 障碍的占地并集；障碍与孔洞重叠时只扣一次。
家具、门扇开启区和一般禁放区不扣净地面面积；其对家具可放区域的影响另行计算，不改写房间净面积。
障碍超出房间的部分按交集计算，同时产生归属/越界待处理问题；确认前必须解决。
未校准时物理面积为空，不将来源 px² 当成 m²。

## 3. 分离的容差配置

首期固定 `geometryPolicyVersion=GEOM-P1-1`；后端保存/确认使用同一版本，不从相机缩放推断业务容差。

| 参数 | 校准后默认 | 未校准预览 | 用途 |
| --- | --- | --- | --- |
| 数值比较 epsilon | 0.01mm | 0.000001px | 稳定数值比较；不用于吸附或隐藏冲突 |
| 最短有效边 | >1mm | >0.1px | 排除退化边；短于阈值须修复后确认 |
| 最小有效区域 | >1mm² | >0.01px² | 排除退化环，不代表房间业务最小面积 |
| 已知共边距离容差 | 1mm | 不作物理确认 | 仅检查 SHARED_PARTITION 登记的边段 |
| 同级重叠面积容差 | 1mm² | 0.01px²（预览） | 超出时阻止相关空间确认；不套用距离容差 |
| 父子越界面积容差 | 1mm² | 0.01px²（预览） | 子空间超出父空间的面积 |
| 交互吸附距离 | min(8 CSS px / 屏幕 px每mm, 20mm) | min(8 CSS px / 屏幕 px每来源px, 2来源px) | 仅用于明确开启的吸附操作 |

共边比较限定登记的对应边段，以双向最大点到线段距离与覆盖端点范围判断，不对全场景任意近边自动建关系。
自交、孔洞越界和重复顶点按几何有效性规则检查，不能因重叠面积很小就忽略非法拓扑。
数值配置的变化必须更换 policyVersion 并重新核验受影响确认；识别误差标准独立见 [附件 D](recognition-validation.md)。

## 4. 稳定顶点、局部轴与矩形锚点

`designGeometry.outer` 保存坐标，同时保存一一对应的 `outerVertexIds`；孔洞使用 `holeVertexIds`。
顶点 ID 随坐标移动不变，环起点重排和方向规范化须同步重排 ID，不按数组下标定位编辑对象。
边由两个相邻稳定顶点 ID 标识；加/删点时新建/退役 ID，不能复用其他顶点 ID。

校准后的矩形使用持久 `rectangleFrame`：`angleDeg` 和四角 ID `u0v0/u1v0/u1v1/u0v1`。
U 轴方向为 `(cos θ, sin θ)`，V 轴为 `(-sin θ, cos θ)`；宽沿 U，深沿 V。
首次导入矩形时，边按无向直线角先规范到 (-90°,90°]，选择与世界 X 轴夹角绝对值最小的边方向作 U，等角时取非负角；结果在 [-45°,45°]。
按 U/V 投影最小/最大值分配四角 ID，随后保存 frame，不在每次渲染或重排顶点时重新推断。
若几何不是符合容差的矩形，frame 为 null，不从包围盒创建矩形编辑模式。
未校准编辑稿 frame 为 null；校准时明确建立矩形 frame。重校准时随变换更新方向，不重新选择 U/V。

默认固定 `u0v0`，即局部左下角；用户可选其他角，但必须提交角 ID，旋转房间不会切换宽深定义。
普通顶点/边编辑破坏矩形前，用户明确转换为多边形模式并清空 frame；宽深编辑不能继续作用于已非矩形轮廓。

## 5. 操作表

所有操作针对当前工作坐标；物理长度输入只用于 WORLD_MM。选中边有明确方向 A→B，UI 高亮固定端点。

| 操作 | 输入/固定对象 | 移动规则与受影响顶点 | 结果规则 |
| --- | --- | --- | --- |
| 整体移动 | spaceId、位移 Δ；无固定点 | 外环和孔洞全部加 Δ；frame 角度不变 | 室内附属障碍/开口不默认跟随，须显式选为同组并预览关联影响 |
| 矩形宽深 | widthMm/depthMm、anchorCornerId；固定选定角 | 保持 θ；按固定角对应的 U/V 符号重建其他三角坐标；ID 不变 | 宽深均为正且边有效；有孔洞的空间首期禁用整体宽深编辑，改用边界编辑 |
| 顶点拖动 | vertexId、目标点 P；固定其余顶点 | 只移动该顶点，相邻两条边重连 | 不承诺相邻边方向或长度不变 |
| 边平移 | A/B 顶点 ID、法向偏移 δ；固定其余点 | A/B 同加 δn，n=sign(环有向面积)×(-dy,dx)/长度，朝该环包围区域内部；孔洞正偏移朝孔洞内部 | 原边方向不变；相邻边可倾斜；预览显示全部受影响边 |
| 边长，自由模式 | 有向边 A→B、目标长度 L；固定 A | B'=A+L×unit(B-A)，其余点固定 | 选中边方向不变；B 的下一条边可改变方向，不能声称保持正交 |
| 边长，正交局部模式 | A→B、L；固定 A；下一顶点 C 的后继为 D | 仅当 BC 垂直 AB 且 CD 平行 AB 时可用；B/C 同加 (L-旧长)×unit(B-A)，其他点固定 | 保持 AB/BC/CD 方向；不跨更多顶点自动传播；不满足条件则禁用此模式 |
| 增点 | 边 A/B、边上投影点、新 ID | 在 A/B 之间插入点，其他点固定 | 两条新边均须有效；明确与原边的关系失效/重建 |
| 删点 | vertexId；其余点固定 | 删除点并连接前后点 | 环至少三个不同顶点；矩形先转换模式；相关边关系待重建 |
| 校准 | 原图参考点、实际长度、新变换 | 当前全稿通过旧逆变换和新变换转换；未校准稿直接转换 | 保留编辑与顶点 ID，整体预览后原子应用；取消则不写入 |

原始识别与底图在普通设计编辑时不变。整体移动不意味着原图建筑和关联门窗也被移动；不一致将作为约束问题提示。
局部操作不自动移动邻房。交互提交前如出现自交、倒置矩形、退化环或非法孔洞，显示失败原因并回到操作前几何。
合法但造成邻室重叠/既有共边不连续的操作可保存为有问题草稿，取消相关确认；不静默吸附修复。
原始识别已经无效的轮廓允许保留为待修复草稿；这不等于允许新交互静默制造非法轮廓。

## 6. L 形边长确定性示例

外环（毫米、逆时针）：`[(0,0),(6000,0),(6000,3000),(3000,3000),(3000,6000),(0,6000)]`。
选中 A=(6000,3000) → B=(3000,3000)，长度 3000mm，改为 4000mm：

- 自由模式：B 变为 (2000,3000)，C=(3000,6000) 不动，BC 倾斜。
- 正交局部模式：B 变为 (2000,3000)，C 变为 (2000,6000)，其他点不动，保留正交 L 形；面积 27㎡→24㎡。

两个操作都可撤销，但 UI 必须明确选择模式，不能靠开发者猜测传播范围。
验收还须覆盖顶点重排后的矩形宽深不交换、120mm 墙厚间隔不报裂缝、孔洞与柱占地不重复扣面积。
