# CAT-003 供应商商品尺寸与预览适配

日期：2026-10-14。用户确认 `幻影系列-灵动系列2061009.xlsx` 的“规格(长×宽×高)”数字统一为毫米，并要求先完善系统导入，再自行在页面正式测试。

## 范围与决定

- 系统在预览时解析该供应商目录；严格三段尺寸自动提取毫米值，明确的双宽度写法在 2026-10-15 起拆为两个规格；高度二选一仅保留可确定的宽深，原文供人工复核。
- 商品导入不再推断或保存品类码；D 列颜色/材质混合原文不拆为推断码。
- J 列作为展示价格 `retailPrice`，L 列作为出厂报价 `factoryPrice`。缺 J 列或图片的行预览提示，不把出厂价充当展示价。
- 复核首行后发现原表 G/H/I 分别是包数、体积（CBM）、重量（原表未明示重量单位），此前未映射。现增加独立的变体字段并在预览、详情展示；包数不填入“数量”，缺失单元格保持空值。既有数据库由显式 SQL 迁移添加字段。
- F 列说明有多行内容；清洗只归并行内多余空格，保留段落换行，预览使用多行文本框。F 列纵向合并单元格表示范围内商品共用同一段说明，按合并区域首格内容复制到各商品行；普通未合并空白行不从邻近商品猜测继承。合并区域内被隐藏的旧单元格值不覆盖可见的首格内容。
- Excel 数值先消除二进制浮点显示噪声，再按存储精度保存：重量最多保留 3 位小数（例如 `86.49999999999999` 归一为 `86.5`），体积最多保留 9 位小数；不把所有重量强制截成 1 位小数，以免丢失供应商真实的 0.01 或 0.001 精度。页面可按展示需要格式化，但数据库保留归一后的数值。
- 标准模板新增宽度、进深、高度的毫米字段；宽深须成对，取值 1~100000 mm。供应商严格三段原文与已填结构化尺寸冲突时阻止该行导入。
- 成功导入时将确认后的尺寸写入 `rspu_variant.dimensions`，保留尺寸原文；重复规格更新非空尺寸。画布商品候选从毫米换算厘米，缺尺寸或缺展示价的商品不作为当前可排版候选。
- 该适配只提供可信商品尺寸基础。空间确认、排版确认、尺寸匹配推荐仍由后续任务实现。商品主档当前不按品类码存储。
