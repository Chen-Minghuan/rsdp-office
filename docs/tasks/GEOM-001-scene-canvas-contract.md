## 目标与验收

用户完成识别并应用到画布后，房间形状、方向、位置、尺寸、面积和底图保持对应，为后续数值编辑和家具排版提供可靠世界坐标。
本任务完成导入契约与对应显示，不承担完整尺寸编辑、确认工作流、商品推荐或效果图。

- [ ] CAD 与 PDF/PNG 结果分别通过适配层进入统一场景，来源和质量可追溯。
- [ ] 命名与未命名空间均有稳定映射，文件同名或重识别不误配已有空间。
- [ ] 矩形和 L 形/凹多边形保留原轮廓，面积不取包围盒面积。
- [ ] CAD 原始单位与毫米归一化状态明确；未知比例场景标为待校准。
- [ ] 底图、空间和实际支持的墙/门窗/候选家具共用一致变换，实际尺寸正确。
- [ ] 平移/缩放/切换单空间视图不改变业务几何；指针正逆变换一致。
- [ ] 保存恢复后几何、ID、来源和版本保持一致；旧草稿迁移不猜测真实单位。
- [ ] 服务失败、无空间及部分识别有明确反馈；不清空此前编辑稿。

## 现状与依赖

当前 `importFloorPlanToZones` 已保留 rooms 多边形并为未命名空间提供名称兜底，但矩形属性与毫米轮廓仍混用。
`CanvasBoard` 将轮廓分别映射到固定 SVG 宽高，未统一底图、对象和指针变换；尺寸输入未同步多边形。
`FloorPlanService.confirmRooms` 重建空间时未保存多边形，面积按宽深计算，需要先修复以免确认丢失轮廓。
既有实现记录见 [导入记录](GEOM-001-canvas-import.md)，其中 mock PNG 不构成真实识别验收。
CAD 响应已包含多边形、单位信息、drawingBounds、preview 与质量数据，需要在前端/业务模型中保留。
PDF/PNG 真实样本验证依赖真实 vision 服务；未接通时可用契约 fixture 验证适配，但不能将其称为真实识别验收。
目标细节以 [Spatial 协议](../../Spatial_Scene_数据协议规范_V1.0.md) 和 [实施方案](../../Spatial_Canvas_Engine_前后端开发实施方案_V1.0.md) 为准。
编码前遵循 [几何规则](../spatial/geometry-rules.md)、[固定接口/存储](../spatial/api-storage-contract.md)、[确认失效](../spatial/confirmation-rules.md)与[真实样本](../spatial/recognition-validation.md)。新增表/主键/快照/回执职责已定义，实际 DDL 尚待实施。
