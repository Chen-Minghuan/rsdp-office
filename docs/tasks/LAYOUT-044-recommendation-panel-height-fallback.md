# LAYOUT-044 推荐面板矮视口滚动兜底

状态：已修复并通过模拟回归

日期：2026-11-18
分支：fix/recommendation-panel-scroll-fallback
关联：LAYOUT-041（推荐列表内部滚动修复）

## 问题

小屏笔记本或浏览器放大（等效于有效视口高度缩小）时，右侧「款式推荐」面板的商品列表被压到接近 0 高：滚动条消失、候选卡片不可见，档位按钮下方的说明文字被底部结算条截断。

## 根因

面板纵向 flex 链中除商品列表外全部区块为 flex-none（不收缩）：页签、空间信息、警告条、当前家具、搜索/色系、档位、结算条合计约 500~600px。列表作为唯一 flex-1 min-h-0 的弹性元素承受全部高度缺口，视口不足时被压至 0；且面板没有任何兜底滚动机制，溢出内容被 overflow-hidden 直接裁掉。浏览器放大只是缩小了有效 CSS 视口高度，与减小窗口等价。

另发现应用外壳约定最小有效高度 600px（app.vue `min-h-[600px]`），视口低于该值时整页滚动，属既有全局行为，本任务不改变。

## 修复

保持「仅商品列表自滚、其他区块不动」的交互哲学，新增纯 CSS 兜底：

- DesignSidebar.vue：空间信息、警告条与推荐组件包入 `flex-1 min-h-0 overflow-y-auto` 兜底滚动层（data-testid=sidebar-fallback-scroll）；结算条移出该层，以 flex-none 钉底。高度充足时层内容不溢出、无滚动条，表现与原布局逐像素一致；高度不足时滚动层出现滚动条，上方信息区可滚走，结算条始终可见。
- ModuleProductRecommendations.vue：列表 `min-h-0` 改为 `min-h-[160px]`，任何视口下至少保留一张卡片高度与可用滚动条；压不下的高度由兜底滚动层承接。
- 档位按钮改为单行：`flex-wrap` 改为 `flex-nowrap`，tiers 增加 short 短标签（全部 / ≥85% / 60–85% / <60%），完整档位名移入 title 悬浮提示；卡片上的档位文案仍使用完整 name。消除数量位数导致的换行，并省出一行高度。

滚动穿透不做隔离（浏览器默认链式行为）：仅在极端视口下外层才可滚，滚轮滚完列表自然衔接外层到达结算条，符合直觉且零实现成本。
