# RECOG-002 Qwen3-VL-Plus 图片/PDF 接入

状态：已编码待真实验证
更新日期：2026-10-14
基线：当前工作区，保留现有 Spatial/画布改动

## 目标与范围

用户选择 `qwen3-vl-plus` 识别图片/PDF。后端读取百炼密钥，发送图像请求并适配为现有房间/预览契约。
PDF 渲染选定页，图像与轮廓共用标准底图像素坐标；实际尺寸未经校准不生成虚构毫米或面积。
本任务不重写 CAD、Spatial 画布或完整确认流程，不启动用户自行管理的前后端服务。

## 验收与步骤

- [x] 配置 `DASHSCOPE_API_KEY`、可选地域地址和模型；未配置时明确失败，移除隐式演示回退。
- [x] PNG/JPEG 及 PDF 选定页转换为同一模型输入/预览，页码异常明确反馈。
- [x] 请求鉴权、JSON 输出解析、失败反馈与非法轮廓校验；来源、单位与原始结果保留。
- [x] 上传页面显示持久化预览、待校准状态和真实错误，PDF 可指定页码。
- [x] 请求/适配/页选择单元测试、Java 测试和前端构建通过。
- [x] 更新配置文档、进度及证据；实际百炼调用与真实样本验收单独记录。
- [ ] 配置真实密钥后的百炼调用和附件 D 真实样本质量验收。

## 决策

- 使用百炼兼容 Chat Completions 接口，默认北京地址，可配置业务空间/其他地域地址。
- Qwen3-VL-Plus 以图片输入；PDF 由 PDFBox 渲染用户选定页再提交，避免把 PDF 直接当 image_url。
- 输出轮廓在标准底图像素框架内，毫米尺寸待人工可靠校准；模型命名/几何仍需人工复核。
- 保留旧 `rsdp.vision.url` 外部识别接口模式（配置该地址时优先使用），不自动退回演示数据。
