# LAYOUT-023 通道宽度与净距规范阈值提示

状态：已实现并通过验证
更新日期：2026-10-22
负责人：按实际填写
基线/交付版本：工作区
关联：[LAYOUT-021](LAYOUT-021-canvas-aisle-channels.md)

## 目标与验收

触发：用户在排版面板编辑通道宽度/两侧净距。
结果：低于提示阈值（初始策略：宽度 < 900mm）时给出可见警告文案，明确"提示性策略、非规范强制"，不拦截输入与排版。
范围：纯前端提示；阈值集中定义便于调整；不涉及服务端。

- [x] 验收项 1：宽度 800mm 时面板出现阈值提示，900mm 时消失；净距不提示（阈值 0）
- [x] 验收项 2：提示不影响提交/确认流程；e2e 专项断言

## 现状与依赖

- 通道宽度/净距现状为可调整策略（LAYOUT-021 文档明确"非规范"）；面板卡片已有宽度/净距输入。
- 依赖 LAYOUT-021 已实现的 `LayoutChannel` 与面板结构。

## 实施步骤

- [x] 定义阈值常量与文案（注明策略非规范）：`CHANNEL_WIDTH_HINT_MM = 900`（layoutChannels.ts）
- [x] 面板通道卡片接入提示（`data-testid="channel-width-hint"`）
- [x] 专项 e2e 断言 + 回归，更新文档
