# LAYOUT-008 家具多选与整组操作

状态：已实现并通过专项模拟验证
更新日期：2026-10-16

## 目标与范围

单空间设计画布支持 Shift/Ctrl/Command 点选增减家具、空白处拖框选择、整组拖动和批量删除。单选时保留原属性编辑和单件删除；平移工具及逐件添加互不混用。切换空间、工具或按 Esc 清除选择。

整组移动保持相对位置，提交前按旋转占地检查当前空间多边形及组外家具，不合法时整组不写入。移动和批量删除各生成一次撤销记录，保存后只取消当前空间排版确认，保留其他空间的数据和确认。

## 实现

- 画布维护当前空间家具 ID 集合；父组件原有单个 `selectedId` 继续用于单件属性编辑，多选时为空。
- 拖动中仅显示位置预览；松开后由 store 统一校验并提交。复用逐件放置的占地和碰撞规则；组移校验采用 0 mm 额外离墙/家具净距，以保留既有布局的原有间距，仍禁止穿墙和相交。
- 家具操作只取消其空间家具的 `layoutConfirmed`，不会调用会切换到总览的空间几何失效函数。
