# LAYOUT-015 严格按四张参考图排列

日期：2026-10-20。状态：已实现并通过专项验证；用户实际方案待核对。

## 最新要求与范围

后续用户纠正：参考图的 6/12/8/16 仅是示例数量，实际排数、列数及组合数量应按场地决定。当前行为以 [LAYOUT-016](LAYOUT-016-space-adaptive-reference-layout.md) 为准；本任务下方的固定总件数规则保留为历史过程，不作为当前容量契约。

用户提供一字屏风卡位、L 型屏风卡位、一字职员台、L 型职员台四张排布图，要求严格按图排列。本任务覆盖 LAYOUT-014 中职员工位自动多排/比较通用候选的决定；会议桌椅、预览、分组与手动家具保留继续沿用。未提交工作区的既有改动保留。

## 图例契约

- 一字职员台与一字屏风：单排为同向 3 列×2 排、6 件，排间默认净距 1000mm；对坐为两组 3 列×2 排、12 件，组间默认净距 1600mm。上排垂直反射，座席朝上、柜侧仍在右；下排保持基准方向，座席朝下。
- L 型职员台：单排同向 3 列×2 排、6 件；对坐两组 3 列×2 排、12 件，上排右上转角/座席朝外，下排右下转角。两种方式默认组间净距均 600mm。
- L 型屏风 F：同向 4 列×2 排、8 件，上下排之间默认净距 900mm。
- L 型屏风 T：左右两组，每组 2 列×3 排、6 件，共 12 件；每排左右镜像，转角向中间，组间水平净距默认 900mm。
- L 型屏风 C：左右两组，每组 2 列×2 排、4 件，共 8 件；上排两件向中间下伸，下排两件向中间上伸，组间水平净距默认 900mm。
- L 型屏风十字：上下两组，每组 4 列×2 排、8 件，共 16 件；每行两个相邻十字，依照参考图交替镜像，组间垂直净距默认 900mm。
- 图例内桌面紧贴，不因同排留缝或目标人数而拆分；组间净距可显式调整。空间或禁放区无法容纳整个图例时返回无法应用，不退化为单组或部分卡位。

## 实现

`planStrictArrangement` 改为完整组合的确定性槽位；移除 T/C/十字随空间自动减少组数的行为，修正 T 形原 10 件与十字原 8 件错误。职员工位在推荐/固定入口均使用当前选中的严格预设，不再调用通用填充器或截断目标人数。

L 型屏风通过当前样式元数据使用右下圆角 L 轮廓，镜像/旋转由统一实例变换实现；一字与 L 型对坐补齐座席示意，画布、待应用预览与方案平面共用图例。座席示意附于职员桌模块，不作为独立已选商品或会议椅实例计数。

新应用写入规则版本 `2026-10-reference-v4`。旧布局与旧确认不静默改写，界面预览显示新图例，用户重新应用后替换当前自动组；手动家具和其他空间保留。组间距设置在面板明确展示，图例内留缝入口仅会议布局保留。
