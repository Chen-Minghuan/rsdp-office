# GEOM-015 窗与开口标注

日期：2026-10-27。状态：已实现并通过构建、纯函数测试、专项 UI mock 与后端测试；真实数据库持久化与用户业务验收待补充。

2026-11-03 用户修订：窗改为沿墙线段标注，下文矩形描述为首版记录；2D 规则见“沿墙窗线”，3D 规则见“嵌墙立体窗”，墙高统一修订见文末。

## 背景

目标画图工具条含「窗」按钮；当前障碍类型（`SpatialObstacleKind`）只有 COLUMN / SHAFT / NO_PLACEMENT / DOOR_CLEARANCE / OTHER，无窗/开口标注。LAYOUT-029 盘点已确认：识别层不产出门/开口，`openings` 契约层恒空。

## 目标与范围（定稿）

用户明确：窗和障碍物一样挂在**单空间**内（`zone.obstacles`），不做跨空间对象。

- 障碍体系新增 `WINDOW` 类型：单空间焦点内沿墙拖出矩形标注窗位，复用障碍的创建/移动/角点调整/删除/贴墙吸附与撤销链路。
- 语义定稿（首版）：窗为**标注型约束**——不扣净面积（`excludesFloorArea=false`）、不参与排版避让（不进 `zoneLayoutExclusions`、不算通道疏散阻挡）、不参与服务端排布校验（`OfficeLayoutValidationPolicy` 跳过 WINDOW 但仍校验几何有效性）。窗下能否放矮柜等业务规则待确认后再决定是否引入避让。
- 识别层自动提取开口不在本任务范围（仍是人工标注首版）；离地高度/窗台高字段未入契约，首版只标平面位置与宽度。
- LAYOUT-029 入口联动复核：窗不算通道阻挡、不作为入口代理，提示口径保持不变（仍以门洞净空为唯一入口代理）。

## 验收标准

1. 单空间焦点内可拖出窗矩形，画布标注「窗 · 宽×深」，可移动/调整/删除/撤销。
2. 窗不扣净面积、不改变空间轮廓、不进入排版排除区；已确认排版与窗重叠时服务端保存不被拒绝。
3. 纯函数测试、后端测试、`pnpm build`、`e2e:space-review`（含窗标注断言）、MOCK 冒烟、`git diff --check` 通过。

## 2026-11-03 沿墙窗线

用户要求窗用线条标注并吸附墙体。当前设计画布选择“窗”后沿墙拖线，绘制起点确定最近的真实空间墙边，两端投影并限制在同一有限墙段，支持水平、竖直和斜墙。绘制中即预览蓝线；保存后用线段及两端手柄显示，不再显示矩形填色或宽深参数，只保留“长度 mm”。整窗移动吸附最近可容纳墙面并保留长度，所在墙太短则保留原位；端点拖动、数值长度编辑贴墙，超过墙长的数值明确拒绝。窗的贴墙行为独立于柱/家具可开关的吸附设置。

数据继续复用 `WINDOW` 的 `geometry: POLYGON/WORLD_MM`，存储中心线两侧各 0.5mm 的标注带，仅用于兼容现有 JSON、几何校验、模板及后端保存，不代表真实窗厚。画布显示和编辑使用中心线端点，属性只显示长度；不扣净面积、不加入排版避障的语义不变。旧矩形窗通过长轴中心线兼容显示，原数据不自动重写，编辑时才转为沿墙标注带；3D 构建也从同一中心线生成薄窗片，旧矩形深度不再当作窗厚。此阶段未新增实际高度采集或墙体开洞；薄窗片的 3D 表现已由下节修订。

实现：`obstacles.ts` 增加窗线构建、长轴兼容、墙边投影和沿墙长度编辑；`CanvasBoard.vue` 使用线段预览/点击命中/两端编辑并沿用保存、确认失效与撤销链路；`SpatialCanvas.vue` 总览同步显示线段；`whiteModel.ts` 共用中心线。接口、后端业务规则、房间轮廓与家具坐标未改。

## 2026-11-03 嵌墙立体窗

用户指出薄窗片漂浮在完整墙面上，要求可辨认的实体窗。3D 场景现从同一窗线匹配有限墙段，生成沿墙宽度、竖向范围和洞口；含窗墙使用 2800mm 示意墙高，其他墙保持原半高剖切。墙网格直接拉伸带孔轮廓，窗洞贯穿墙厚，保留两侧墙垛、窗台下墙和窗楣；同墙多个分离窗保留中间墙垛，重叠洞口合并以避免三角化破面。窗模型包含铝合金外框、分格窗扇、透明玻璃、双侧把手和凸出窗台，支持水平、竖直和斜墙。

平面位置/长度来自设计窗线；旧矩形仅在 3D 副本上投影贴墙，原标注不自动修改。窗高 1200mm、窗台高 900mm 和墙高/厚均是渲染估计（悬停窗提示），并非实测值或真实商品模型；不新增接口、持久化字段、排版避障或面积扣减。设计与方案页复用同一渲染器。验证结果见 [RENDER-004](RENDER-004-3d-furniture-interaction.md) 本日“嵌墙立体窗”记录。


## 2026-11-03 墙高统一修订

用户指出含窗墙与无窗墙高低不一。撤销按有无窗户选择墙高的逻辑，所有空间边统一使用 2800mm 示意墙高，柱/井道使用同一高度常量。窗户只派生墙上洞口，添加/删除窗都不改变墙高；窗洞、窗框与窗台继续保留。该修订覆盖上节“其他墙保持半高”的实现记录，仍不回写设计几何或假定实际层高。验证见 [RENDER-004](RENDER-004-3d-furniture-interaction.md) 的“墙高统一追修”。
