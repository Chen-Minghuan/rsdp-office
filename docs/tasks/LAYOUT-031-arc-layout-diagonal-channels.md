## 目标与验收

触发：用户选择弧形布局模式，围绕圆心排布座位；斜向通道绕圆心旋转定位（手柄拖动）。
结果：先实现弧形排版引擎（排布沿弧线展开、容量与确认规则明确），再把斜向通道作为该模式的通道形态：绕圆心旋转、径向宽度、与正交通道同一套确认/持久化/失效规则。
范围：弧形模式 + 斜向通道整体；不与正交网格混排的组合规则在任务内定稿。

- [ ] 验收项 1：弧形排版预览/应用/确认链路打通，容量与间距参数明确
- [ ] 验收项 2：斜向通道旋转拖动、宽度、确认压占校验与正交通道一致
- [ ] 验收项 3：专项 e2e + 回归；服务端核验同步（参照 LAYOUT-022）

## 现状与依赖

- 现状：系统无弧形布局；通道仅正交两向（LAYOUT-021）。参考工具（Kimi 部署版）有弧形模式与斜向通道绕圆心旋转手柄。
- 这是独立大块：建议拆子任务（排版引擎先行，通道后置）；启动前需与用户确认弧形排版的具体业务场景与参数。
