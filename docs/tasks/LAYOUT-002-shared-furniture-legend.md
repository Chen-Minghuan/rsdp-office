# LAYOUT-002 单位模块复用办公家具图例

状态：已实现并通过专项验证
更新日期：2026-10-15
基线：当前工作区；保留空间核对、模板及单空间视图改动。

## 目标与验收

单空间设计的全部单位模块使用手动布局现有的可见办公家具目录及 `ManualFurnitureGlyph` 参数化线稿。目录、默认毫米尺寸、规格选项与画布形状来自同一份模板，不复制图例。模块不要求预先绑定商品；原商品推荐和旧家具数据继续兼容。

验收：全部分类/可见图例可选、修改尺寸后实际排版尺寸一致、画布使用相同线稿，刷新/撤销保留 templateId 与空间/空间模板归属；未放下或无效尺寸不得清空原有布局；单空间隔离与既有推荐链路回归。

## 范围

本轮复用家具目录和图形，保留原参数排版入口；不重写手动布局，不声称完成异形边界、家具碰撞及正式商品匹配服务。

## 实现

- 单位模块直接使用 `furnitureCatalogTemplates`/`furnitureCategories`，与手动布局同为 9 类、28 个可见图例；隐藏的 U 桌不在两处目录中展示。
- `FurniturePreview` 复用 `ManualFurnitureGlyph`，卡片和画布同源；圆角 L 桌、椭圆桌、座椅及柜体等保留参数化细节。为 CSS 缩放画布补偿线宽，手动布局默认显示不变。
- 常用规格和自定义宽深使用毫米；兼容原排版计算的最小规格为 10mm。已知毫米空间明确按 1000mm/米处理，不能被旧像素比例覆盖。
- 新家具保留 `furnitureTemplateId`、尺寸、空间 ID 及空间模板引用；`productId` 兼容字段为空时表示尚未绑定商品，选择图例不自行选择商品。旧商品家具按品类适配线稿，原保存数据不重写。
- 沿边旋转占地不改写物件实际宽深；无效或放不下时不清空旧布局。新布局可撤销、刷新及确认，商品推荐入口保留。
