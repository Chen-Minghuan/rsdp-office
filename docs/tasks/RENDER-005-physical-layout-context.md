# RENDER-005 实际空间与排版约束参与效果预览

日期：2026-10-20。状态：实现与专项验证通过，真实模型视觉验收待完成。

## 问题与实现

用户反馈效果图仍含数字清单与户型小图，家具排列也未忠实对应实际场地。原提示逐件列出世界坐标，容易成为模型照抄的文字内容；仅靠概念块不足以传达狭长比例、实际间距及 L 型结构。

- 新增 RenderLayoutContext，按当前设计多边形与旋转家具外包占地计算毫米数据：房间宽深、净面积、主模块数量、行列中心带、四边实际离墙净距、共截面最近相邻模块的横纵净距。紧贴接缝不视为通道，异形墙面按真实多边形求交，保留禁放区域。混合尺寸/朝向的行列数只作辅助，具体结构以空间引导为准。
- 提示改用汇总约束，不发送逐件原始大坐标清单；商品对应序号压缩为连续范围。要求保持长宽比例、紧贴关系、排列方向和镜像，禁止图板、清单、编号与拼贴。
- 按 sourceAnalysisId、明确修订、图像摘要、项目和稳定空间 ID 核对原户型识别来源；原识别轮廓仅作为来源证据，当前设计几何优先。来源失效时保留当前几何并明确回退；不按名称猜空间，不重新解析或修改用户设计。
- 当前来源没有可靠结构化门窗数据，标记未知；不声称已识别门窗。整张原户型图片不送入模型，避免被画成成品插图。层高及装饰仍为概念假设。
- 无文字立体引导补充 L 型桌占地、旋转及镜像，保持当前模块预留尺寸；不擅自按商品尺寸重新排版。
- 快照增加来源比例/轴向、排版设置、镜像、分组和主模块/椅子角色。测量附件保存在任务元数据，响应单独返回 layoutContext，不混入用于历史判定的几何快照。页面新增展开面板核对实际测量与来源。

## 实际验证

- 只读核对用户当前画布与已有生成记录，未修改业务数据或重新收费生成。该空间 24 个主模块，8 排×3列；按实际几何复算左右约 926 mm、上侧 498 mm、下侧 1626 mm，7 处纵向净距各 600 mm。配置默认离墙值不代替实际测量值。
- 使用上述几何构造独立测试：验证异形净面积、实际离墙、相邻净距、椅子角色排除、镜像/禁放区域、稳定 ID 来源匹配，以及跨项目或图像摘要不符时回退。
- pnpm build 通过；pnpm e2e:render-preview 通过，隔离前端与 API mock 覆盖测量展示及既有任务/失败/历史/幂等流程。
- Java 全量 172 项：169 通过，3 项数据库环境未配置跳过。最终相关 24 项再次通过。
- 人工查看按该狭长异形几何生成的空间引导 PNG，确认 8×3 个 L 型代理桌、真实轮廓与无文字输出；这是本地生成输入检查，不是供应商效果图验收。
