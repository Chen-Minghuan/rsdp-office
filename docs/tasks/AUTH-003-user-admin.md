## 目标与验收

触发：项目成员功能落地后发现系统没有任何创建账号的入口（无注册接口、无用户管理页），第二个同事要成为负责人/协作者只能手工 SQL。
结果：启用既有 `office_user.role` 字段（仅 ADMIN / USER 两档，不建组织树/RBAC）；管理员可创建用户、停用/启用、重置密码；项目负责人仍在项目内从已有账号中指定，与全局角色无关。

- [x] 管理员接口逐接口在服务端校验 ADMIN（认证关闭的开发模式放行，与 PROJECT-004 同一约定）
- [x] 创建用户：用户名格式与唯一性、显示名必填、初始密码至少 6 位、角色仅 USER/ADMIN（缺省 USER）；只存 PBKDF2 哈希
- [x] 停用：不能停用自己、至少保留一位在用系统管理员；停用即删除该用户全部会话
- [x] 重置密码：至少 6 位；重置后该用户全部会话失效
- [x] 删除账号：不能删自己、至少保留一位在用管理员、仍是项目负责人的账号拒绝删除（协作者关系与会话一并清除）
- [x] 接口与列表绝不返回密码哈希
- [x] 前端用户管理页（/users）与侧栏入口（仅管理员可见）

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/office/admin/users` | 用户列表（不含哈希） |
| POST | `/api/v1/office/admin/users` | 创建用户 `{username, displayName, password, role?}` |
| PATCH | `/api/v1/office/admin/users/{userId}/status` | `{status: active\|disabled}` |
| POST | `/api/v1/office/admin/users/{userId}/password` | `{password}` 重置并失效会话 |
| DELETE | `/api/v1/office/admin/users/{userId}` | 删除账号；负责人账号拒绝 |
