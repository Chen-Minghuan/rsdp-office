# CAT-008 测试站商品页恢复公共库开关

日期：2026-11-19

基线：`test=935da34`。

## 问题与范围

用户在 Office 测试站商品页看不到公共库开关。测试版页面会查询开关状态，但模板没有按钮，也没有调用已有设置接口的交互；主分支较新的商品页已经包含该入口，尚未进入测试分支。

只同步恢复开关所需的状态、交互和模板，沿用现有后端权限与接口；不整合主分支其他商品维护、报价或本地未提交的画布修改。经销商主号可设置整个工作区的公共库可见性，管理员、负责人和协作者没有独立开关。

## 验收

- 经销商主号可看到开关和服务端当前状态；点击后调用工作区设置接口，成功后刷新商品列表、回到第一页。
- 保存期间禁用按钮，失败保留原状态并展示错误。
- 其他角色不显示开关，权限仍由后端核验；状态读取失败不阻断商品列表。
- 实际测试站的经销商账号能看到入口，真实验证只读，不修改现有工作区开关。
