## 目标与验收

触发：请求自动排版时。
结果：排版引擎枚举有意义的候选组合（桌型/朝向/排布变体），按明确定稿的评分口径排序，面板呈现 Top N 方案卡片（容量、间距、利用率等指标可见），点击切换预览；当前选中与应用语义不变（预览不落库、应用走既有失效链路）。
范围：候选集生成与对比 UI；不改动单方案应用/确认语义。

- [ ] 验收项 1：候选生成维度与评分公式定稿（目标达成/舒适/利用等权重为策略值并注明）
- [ ] 验收项 2：Top N 卡片切换预览，指标与候选一致；纯函数单测覆盖排序
- [ ] 验收项 3：专项 e2e + 排版回归；旧单方案入口行为兼容

## 现状与依赖

- 现状：`planLayoutProposal` 内部对候选有评分排序（layoutPlanning.ts 中按 targetSeats 打分）但只返回单方案；无候选集呈现。
- 依赖：评分口径与本项目确认校验（离墙/通道/座位）一致，避免推荐出会被确认拒绝的方案。
