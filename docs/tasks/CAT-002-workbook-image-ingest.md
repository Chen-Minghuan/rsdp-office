# CAT-002 商品导入时自动提取内嵌图片

日期：2026-10-14。用户明确要求在系统录入商品时直接提取 Excel 内嵌图片并关联商品；此前在聊天中单独上传图片的做法不满足要求。

## 范围与契约

- 商品导入页上传 `.xlsx` 时，预览识别普通锚定图、组合图形中的图片和 WPS `DISPIMG`；预览不写文件或数据库。
- 确认导入同时提交原工作簿和用户编辑后的行。后端重新解析，按工作表索引、物理行号和原商品编码核对；编码被修改且该行有图片时拒绝确认。
- 只有成功入库的行保存图片并写入 `image_assets`，主图同步到商品主档；跳过、校验失败和行事务失败不留新图片。按内容哈希命名复用重复导入文件。
- `ITEM NO.` / `ITEM NAME` 多工作表供应商目录可转换为可编辑预览行。B/C/D/E/F/J/L 列映射见后端 README；尺寸原文和价格仍须人工核对，不据此声称尺寸推荐已完成。
- 供应商表 A 列图片单元格纵向合并时，合并范围内的图片列给范围内每个商品行；各行仍保留独立编码、尺寸和价格。未合并的图片不借相邻行。图片说明出现多个商品编码的合并区域提示复核，用户可逐行取消不适用的图片。普通单行图片说明与商品编码冲突时不自动关联。
- 同一商品的图片按图片在表中的位置排序；默认第一张为主图，其他已选图片为详情图。预览可逐行取消图片和选择主图；确认时后端重新解析原文件并校验图片索引。旧 JSON 确认接口、`.xls`、`.csv` 保留无图导入路径。

## 实现

- `WorkbookImportSource` 解析商品行与 OOXML 图形、WPS 图片关系。组合图形按锚点和子图片说明核对；供应商表识别 A 列纵向合并图片区并按位置收集、去重，避免只读到锚点行或组合中的第一张。
- `EmbeddedImageStore` 校验格式、按哈希保存；`ProductImportService` 在逐行事务前保存、事务失败时删除本行新文件，成功后由现有 `saveImages` 写资产与商品主图。
- 前端预览显示工作表、物理行号、图片数、每行图片缩略图与复核提示，并可设置主图、取消图片；确认时将原文件一起提交。
- 上传上限调整为 150 MB，以覆盖当前 113 MB 的真实工作簿。

## 验证与限制

- 2026-10-14 新增合并图片区与单行多图解析后，Java 测试及指定真实工作簿只读解析测试通过：当时 211 个商品行中 210 行有候选图片；截图所示 A4:A6、A7:A8 和第 16 行均各关联两张图。候选关联数量包含同图分配给多个商品，不能当成原文件独立图片数。合并区域内多个图片说明编码并存时显示复核提示，需在预览中按商品取消不适用图片。
- 新服务的 multipart `/import-confirm` 用“全部跳过”请求验证：211 行跳过、0 行入库、0 张图片写入，商品库仍为空。前端生产构建及 `git diff --check` 通过。尚未执行真实 211 行完整入库与商品详情核对，因此状态为“已编码待集成验收”。
- 本地单机文件目录仍需部署持久化配置。文件系统与数据库不是分布式原子事务，进程在保存文件与数据库提交之间异常退出时可能留下孤立文件，后续需清理机制。
- 上次误操作上传的本地图片文件现已由用户清空；旧映射 JSON 仍在 `backend/uploads/image-imports/`，不参与新导入流程。
- 本轮只运行离线 Java 测试和前端构建，未启动服务、未修改端口、未执行正式入库。用户在原端口重启现有服务后测试新预览和导入。

## 后续验收

在运行的新版本 Java 服务上，用真实工作簿预览、编辑/跳过、确认导入、打开商品详情检查图片与规格；复核冲突图片，分别测试重复导入、已存在跳过、更新和失败回滚。只有完成这些真实链路测试才标记已验收。尺寸拆分与单位处理进展见 [CAT-003](CAT-003-supplier-size-import.md)；正式推荐匹配仍属 RECOMMEND-001。

## `16FMT001` 图片说明不符的补图处理（2026-10-15）

- 用户截图显示原表 A15 两张图片，现有商品 `PR-0211` 无图片。核对工作簿原始 OOXML：两张图确实锚定在 A15，但内嵌图片说明写成 `16NMT014`；同一工作表 A13 的 `16NMT014` 另有两张不同的图。旧解析按说明编码过滤，因而两张 A15 图片均未进入 `16FMT001` 的预览和入库。只读数据库查询确认当前 `16FMT001` 已有商品与规格，但 `image_assets` 为 0。
- 新规则优先使用本行说明编码一致的图片；如本行有一致的图片，仍排除说明不符的多余图片，例如 A14 的一张外来图片。如本行所有图片说明均不符，则将本行锚定图列为候选，但默认全不勾选，并提示逐张确认。用户勾选后，确认导入按原文件提取并保存原图；未勾选不自动关联。
- 导入页增加“仅处理此商品”：将其他预览行标为跳过并开启更新已有商品，避免整批覆盖。该商品的已填写资料、规格报价与图片会一起更新，页面明确提示先核对字段。此入口适用于本次补图；不是只修改图片的专用接口。
- 针对过期图片说明新增回归测试；指定真实工作簿只读解析验证 `16FMT001` 有两张可预览候选图，默认均未勾选。Java 20 项测试与前端构建通过。没有启动服务、改端口或替用户执行补图；真实页面补图结果待用户验证。
