# RENDER-011 三图空间控制与位置几何审核

日期：2026-11-24
分支：`experiment/render-product-agent`
协议：初始实验 `selected-products-multiview-v9-spatial-control`；当前修复 `selected-products-multiview-v10-clean-spatial-observer`

## 目标与边界

把画布已经确定的布局转换为生图模型可核对的输入，AI 只负责商品外观、材质、光照和空间写实，不再自行决定家具位置。保留用户手动点击生成、失败不自动重试收费生图的边界。

本轮实现三图输入、数值地面坐标、程序排列描述和生成后几何审核。普通 Qwen Image 仍不是严格三维渲染器；这些输入用于提高遵从率，不承诺像素级布局还原。阈值是待真实样本校准的实验值。

## 生图输入

1. 图1：`RenderSceneGuide` 生成的无编号 45°结构图，负责最终相机、透视、墙体和家具体块。带 F 版本另存为 `bindingGuideUrl`，只用于商品审核和人工追溯，不再进入生图。
2. 图2：`RenderPlanGuide` 生成的无编号平面控制图，负责地面位置、朝向、数量和通道，不负责最终相机。该图实际进入 `referenceImages`，同时保存为 `planGuideUrl` 和任务 `reference_url`。F/P 关系只通过文字映射和数值坐标传递。
3. 图3：`RenderProductReferences` 生成的带 P 编号商品参考板，只负责外观。一款商品只展示一次，`quantity` 与 F/P 列表决定数量，照片数量不决定家具数量。

三图模式单次最多 12 种商品；超出时在调用生图服务前拒绝。未选商品时只发送图1和图2。

## 统一空间事实

`RenderSpatialControl` 是房间和家具几何的唯一转换入口，版本为 `spatial-control-v1`：

- 世界坐标统一毫米，保留负坐标、异形房间、旋转、L 形桌和镜像轮廓。
- `worldGroundPolygon` 是 `z=0` 的地面接触轮廓，与家具高度和 F 标签锚点分离。
- `plan.groundCenter1000`、`plan.groundPolygon1000` 对应图2。
- `guide.groundCenter1000`、`guide.groundPolygon1000` 对应图1。
- 图片坐标以左上角为原点，x 向右、y 向下，归一化到 `0～1000`；中心严格为 `[x,y]`，轮廓为 `[[x,y],...]`。
- 图1、图2和数值坐标使用相同 `Frame`，避免图片和文字各自计算一套位置。

完整事实保存在任务快照 `snapshotJson.renderProductReferences.spatialControl`，不另建布局映射表。商品映射、输入图 URL 和审核结果也保存在同一任务附件，继续复用 `office_render_preview`。

## 两排直线与排列特征

`RenderLayoutSemantics` 不让视觉智能体猜测布局，而是从世界坐标确定性地生成提示词事实：

- 以主体桌子的旋转坐标系判断侧排和头尾。
- 多主体时，椅子只归入最近主体，避免重复归属。
- 优先使用 `layoutRole=seat`；旧数据没有角色时，以家具类型中的“椅”保守识别。
- 输出两侧是否形成相对直线排、每排 F 顺序、中心共线或垂直偏差、实际相邻中心距离、逐件旋转。
- 输出头尾椅相对主体方向、短边中心线偏差和不得挪到侧排/桌角的约束。
- 明确禁止把两排直线改成交错、弧形、散开或随意角度。

例如九件会议家具会得到 `F5→F4→F7`、`F6→F1→F3` 两排，以及 F8/F9 的头尾居中关系。具体编号、方向和距离完全由当次画布计算，不硬编码商品或房间。

## 生成后几何审核

`RenderGeometryAuditService` 使用结果图、图1和图2，让视觉模型只返回观测，不让它直接宣布数值合格：

1. 检查单一场景、商品板、平面图、编号、拼贴和相机一致性。
2. 返回每个可见家具实例的地面中心和地面轮廓，无效多边形不进入匹配。
3. `RenderGeometryMetrics` 以中心距离和 IoU 为主进行一对一最匹配，类别只加轻量惩罚，`TABLE/DESK` 兼容；禁止一个检测结果同时证明多件家具，也避免类别误判推翻正确几何。
4. 计算中心偏移（相对房间归一化对角线）和地面轮廓 IoU。
5. 输出 `PASS/FAIL/REVIEW/UNCERTAIN`；缺失或重复实例、构图错误可使总审核失败，遮挡或低置信度不能静默通过。

默认实验阈值：中心 PASS/FAIL 为 `0.04/0.10`，占地 IoU PASS/FAIL 为 `0.45/0.20`，最低检测置信度 `0.65`，房间 IoU PASS 为 `0.75`。审核只报告，不自动重新生成。
### v10 独立观测与无编号生图跟进

真实 v9 样本暴露了两种不能靠原审核发现的问题：生图模型复制了参考图上的 F 编号，并把同一编号附近的椅子重复生成；审核模型则照抄提示词中的预期坐标，产生虚假的 0% 偏移和 100% IoU。v10 因此执行两条隔离：

- 生图只看到无 F 编号的图1、图2和带 P 编号的商品板；完整 F/P、数量和排列仍在文字中，带 F 白模仅留作审核。
- 几何审核提示词不再包含 `spatial.manifest()`、预期家具数量或任何预期坐标。视觉模型必须只从结果图穷举可见、重复、额外、无编号和局部遮挡实例，程序随后才用保存的空间事实计算数量、偏移和 IoU。

商品审核也明确：后续输入参考图的存在不属于结果图的拼贴/商品板/平面图错误。上述修复减少复制诱因并让审核独立，但仍不构成硬几何约束，真实数量和外观必须重新生成样本验证。
