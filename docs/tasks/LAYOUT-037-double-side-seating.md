## 目标与验收

触发：桌深足够的桌型（如 ≥1m）参与排版时。
结果：「宽桌双侧坐人」开关（默认策略在任务内定稿）：开启时桌两侧都布置座位、容量按双侧计算；双侧坐人且前后排距过近时给提示（椅背相对，阈值策略值）；开关状态随方案保存并参与确认座位统计。
范围：容量语义与座位生成；不涉及商品变体拆分。
