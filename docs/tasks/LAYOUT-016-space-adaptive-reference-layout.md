# LAYOUT-016 保持参考样式，按场地大小排布

日期：2026-10-20。状态：已实现并通过专项验证，真实用户布局待核对。

## 用户纠正与目标

用户指出 6093×17810mm 的业务二部只预估 6 张，是把参考图的示例数量当成容量上限。最新要求：参考图约束同向、对坐、镜像、转角、紧贴及默认净距；排数、列数和组合数量按真实空间决定。本要求覆盖 LAYOUT-015 的“固定示例总件数/必须整张示例一次放入”决定，保留样式的最小完整单元。

## 当前实现

- 新 `planAdaptiveArrangement` 使用毫米空间多边形，按宽深与离墙距离计算可用排数/列数；比较整个样式横向/纵向以及居中/贴边格网，保持局部朝向和镜像关系。
- 同向单排/F 可逐工位扩展；普通对坐使用完整的上下两件单元，T 使用左右镜像两件单元，C 与十字使用完整四件单元。T 沿纵向连续堆叠、横向留净距；C 横纵组合间留净距；十字横向紧贴、纵向留净距，保持参考图关系。
- 0 人表示按可用空间尽量排布；指定人数时优先满足目标并保留完整单元，因此对坐/T 按两件、C/十字按四件向上取整。容量不够如实显示缺口。
- 已有手动家具和入口/禁放区作为障碍；整单元越界或冲突时跳过该单元，继续利用其余空间。单个方案搜索上限 2000 个模块，超过明确提示，不假装完成全部容量计算。
- 预览、实际应用与旧家具生成适配器共用新规划器；实例保存 `layoutClusterId`，新规则版本 `2026-10-adaptive-reference-v5`。空间确认、商品失效、撤销和刷新仍按 LAYOUT-014 链路处理。
- `planStrictArrangement` 仅保留为参考图样例坐标的测试工具，不再决定实际页面容量。原样例 6/12/8/16 的测试只校验参考图结构，实际容量由自适应专项覆盖。
- 面板改为“按场地排布”，展示实际排/列数与方向，说明目标人数及最小单元。旧保存布局需显式应用更新，预览不覆盖原稿。
