# RENDER-004 3D 家具交互与属性联动

状态：已实现并通过本地验证（P0 完成、P1 完成，P2 类别示意模型已上线、GLB 注册层就绪但无真实模型资源）
更新日期：2026-11-03

## 目标

在 RENDER-003 白模基础上升级为业务对象级交互：3D 场景展示 → 点击家具 → 高亮 → 查看真实业务属性 → 替换商品/模块 → 同步 2D 排版与方案数据；方案页接入只读 3D 交互页签。以 Kimi 参考演示为方向参考（本环境无外部浏览器工具，未做原型黑盒比对）。

## 现状核查发现的真实缺口（实施前）

- 白模 `bindProduct` 直接 `updateObject` 改 productId 和宽深：绕过服务端规格确认、在售核验、清单同步与失效规则 —— 本次修复。
- 白模 `replaceTemplate` 同样绕过 `replaceFurnitureModule` 的碰撞校验、旧选品清除与确认失效 —— 本次修复。
- 白模 `rotateSelected` 直接改 rotation，绕过 `rotateFurnitureGroup` 的占地重校验 —— 本次修复。
- pointerdown 即锁定相机：点击与拖动不分，从家具上起始无法旋转视角 —— 本次修复（6px 阈值，见 `utils/furniture3d/selection.ts`）。
- 无地面选中标记、无轮廓描边分层；无只读模式；方案页无 3D 入口；拖动落点无布局校验。
- 家具渲染为纯白方块：无桌腿/靠背/显示器/屏风等可辨形态，无投影，观感与参考示意图差距大（用户实测反馈「就是一个方块」）—— 本次修复（程序化类别示意模型 + 平行光投影）。
- 附带修复：场景重建不再重置相机（仅空间轮廓变化时取景）；设施材质按色缓存、重建/销毁时释放几何体与独占材质；GLB 组子节点命中沿父链归属同一实例。
- 附带修复：程序化模型几何稀疏（桌腿间/桌沿下有缝隙），旋转后射线可能穿过缝隙导致点选/拖动丢失 —— 每件家具增加覆盖业务占地的不可见命中盒（hit-proxy 子节点，userData 携带实例 ID），点选与拖动命中稳定；e2e 暴露后修复。

- P2 模型层：[modelRegistry.ts](../../frontend/app/utils/furniture3d/modelRegistry.ts)（真实商品 GLB → 类别 GLB → 程序化示意模型 → 白模方块的解析回退链；资源必须声明单位/原始尺寸/锚点；等比缩放只嵌入业务占地、不回写业务尺寸）+ [modelLoader.ts](../../frontend/app/utils/furniture3d/modelLoader.ts)（GLTFLoader 按 URL 缓存去重、克隆实例、缓存释放）。当前未注册任何真实 GLB 资源（无合规模型资产），运行时走程序化示意模型。

## 已知边界

- 3D 拖动/旋转的写回与 2D 共用 `moveObject`/`rotateFurnitureGroup`，失效与撤销语义一致；拖动过程不做实时碰撞预览（与 2D 预览拖动一致，提交时校验）。
- 面板「材质/颜色/RSKU」在商品数据模型中无字段，明确显示暂无数据；商品上下架状态字段未进入 `Product` DTO，在售判断以在售列表查询结果为准。
- GLB 加载链路（缓存/克隆/过期丢弃）已实现但无真实资源可联调，仅有注册/缩放纯函数单测覆盖；示意模型为程序化参数拼装，非真实商品外观，精确外观仍依赖 AI 概念图或后续接入合规 GLB 资产。
- 示意模型高度用实例显式高度或类别默认估计值（面板已标注「渲染估计」），不改变任何业务尺寸数据。
- `e2e:space-review`、`e2e:templates` 在当前 main 既有失败（排版改版遗留，见 RENDER-003 记录），与本改动无关。

## 追修（2026-11-05）：90°/270° 家具 3D 朝向与 2D 镜像反转

用户反馈 3D 空间预览与 2D 排版对不上（L 型屏风卡位椅子跑出桌位、桌子朝向相反）。定位：家具体积 `mesh.rotation.y = -(rotDeg·π)/180` 取反错误——画布 (x,y 向下) → three (x,z=-y) 的映射本身带镜像，顺时针画布角应直接写入正 `rotation.y`（与墙体 `atan2(dy,dx)` 同号）。0°/180° 不受影响，90°/270° 的异形家具（L/U 桌、配椅、屏风侧）在 3D 中呈镜像，正是用户截图中左右墙与中部卡位的错位来源。

修复：`WhiteModelPreview.vue` 家具体积旋转去掉取反并补注释；`whiteModel.ts` 的 `rotDeg` 注释同步更正。8 种朝向（0/90/180/270 × 镜像有无）投影校验：配椅屏幕投影与 2D 约定座位世界坐标的残差从 50–70px（方向各异）收敛到 ≈(0,-14)px 的纯抬升位移。e2e:white-model 新增 L90 卡位回归（对 2D 假设偏差须小于对反向假设偏差的一半）。修复后 8 朝向对照截图已目检，椅子均落回 L 袋口内。构建、白模/模型单测、e2e:white-model、proposal-3d（模拟 API）通过。
