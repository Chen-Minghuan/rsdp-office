# RECOG-007 底图先行与后台并行识别

日期：2026-10-17。状态：已实现，自动验证通过；真实性能及业务验收待实测。基线：5976ebc，起始工作区干净。

用户要求：先显示标准底图，空间识别在后台继续；两个独立模型请求并行；真实阶段与耗时；同图、同页、同处理参数复用底图缓存。

沿用分析/版本表与原图资产，不新增表。后台任务仅更新其独立分析 ID，不写用户设计画布；未知比例仍待校准。旧同步分析接口与 CAD 保留兼容，图片/PDF 页面采用后台入口。任务执行器和模型执行器分开限流；重启中断明确失败，不伪装持久任务队列。缓存仅复用标准图，不缓存模型/人工结果，保留来源哈希、页码、参数与转换版本。

实现：

- `background=true` 选择后台模式。原图/分析头/版本先提交，工作线程使用持久源文件，不持有 servlet 临时上传；标准图单独保存并提交后才等待 AI。原同步入口、CAD、外部视觉服务兼容原协议。
- `VisionTaskExecutors` 分开限制任务和模型线程。独立房名定位与房间/尺寸请求同时在途，汇合后执行原轮廓校正；房名失败保持原有降级提示，不生成假房间。
- `RecognitionProgress` 以单调时钟记录实际完成的 prepare/spaces/labels/contours/save 与总体耗时；页面显示“处理图片 / 识别空间 / 校正轮廓”，无需伪百分比。终态保护阻止延迟回调回退。进度单独更新原始数据字段，不回写旧生命周期/确认状态。
- 标准图缓存包含文件内容 SHA256、页码、最长边、PDF DPI、PNG 转换版本。30 分钟、最多 8 项/64 MiB LRU；并发同键合并，失败不缓存，PNG 字节不能从外部修改。AI 结果及设计几何不缓存。
- 上传页每秒查询；底图先出现并滚动到结果区域。sessionStorage 保存任务 ID、文件描述、页码、隔离键，刷新/返回后只续查；查询失败可重试原任务。完成/失败停查，模型失败保留底图。卸载和请求序号保护旧结果，不自动导入或覆盖画布。
- 保存结果和 DONE 进度存在短暂提交间隔，页面等待进度终态再结束。识别中后端拒绝空间确认、尺寸重读和比例确认。队列满或重启中断明确失败；启动扫描只处理有 processing 的未完成任务，不处理旧同步任务。
