# LAYOUT-018 参考尺寸、座椅图例与场景旋转

日期：2026-10-20。状态：实现与专项验证通过；真实业务验收待核对。

## 用户要求

标记离墙和各组之间的参考间距，补齐其他桌子图例的椅子示例，画布布置场景支持旋转。

## 实现约定

- 离墙数据按实际毫米空间多边形与家具旋转后的外包占地测量；凹角、斜边均通过真实轮廓射线求交，不能用空间外接矩形代替墙面。
- 横向、纵向最近相邻家具组测净距；紧贴单元不标为通道，测量线不穿越空间外部。重复同一走廊只标一次；标注覆盖待应用预览、保留家具及拖动中的位置。尺寸按钮可隐藏标注，单件尺寸仅选中时显示。
- 职员直线/L/圆角 L/屏风以及主管、高管桌显示座席示意，随家具旋转与镜像；目录、预览、应用后画布和方案平面共用图例。示意不增加实际椅子实例或数量，也不代表完成座椅选品。离墙/组间数值按家具外包占地测量。
- 工具栏旋转场景视图每次 90°，提供复位；房间、家具和尺寸图层一起旋转，文字保持可读。相机逆变换用于选择、拖动、框选和逐件放置；适屏按旋转后范围计算。只改变本页视角，不改物理几何/确认、保存数据或其他空间。

## 验证计划

前端构建；四边离墙、横纵组间、紧贴、凹角/斜边、旋转占地与指针逆变换算法；实际 UI 预览、旋转/复位、拖动及尺寸开关；原有参考样式和家具选择回归；截图人工核查。

## 边界

测量为家具外包占地之间的轴向净距。识别出的空间边界不是墙体厚度，示意椅不作为真实家具碰撞包络。未知门窗与真实连续通路仍需现场核验。本轮仅前端，不扩大后端、真实图纸和业务保存验收。
