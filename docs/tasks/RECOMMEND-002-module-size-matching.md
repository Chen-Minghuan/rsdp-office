# RECOMMEND-002 单位模块按毫米尺寸推荐商品

状态：已实现并通过专项验证。
日期：2026-10-15。

## 用户目标与本轮范围

单位模块是家具的预留占地。1200 × 600 mm 的模块可匹配宽不超过 1200、深不超过 600 mm 的真实规格；分别比较两轴，不使用面积代替。允许用户选择旋转 90°，不自动缩小商品或改变已确认排版。

- 右侧按当前画布选中模块或同规格分组读取真实 SKU；以已有画布 JSON 的不可变模块规格/自定义快照作为需求。未确认全部家具、比例未知或过期修订不能读取正式推荐。
- 贴合度为 `min(商品占用宽/模块宽, 商品占用深/模块深)`。默认贴合 ≥85%、宽松 ≥60% 且 <85%、偏小 <60%；全部符合宽深的规格均保留，分档不构成尺寸下限。这些百分比是产品排序初值，不是行业标准。
- 显示商品原始毫米宽深、剩余宽深及所需旋转。高度仅展示；家具品类、结构、出入口和使用净距不由两轴匹配自动证明。
- 仅使用上架、审核通过且未逻辑删除的商品和有效上架变体；缺少可靠宽深的规格计数提示、不参与匹配。无报价可展示尺寸，但不能加入方案。
- 使用明确的毫米字段；兼容历史 `widthCm/depthCm` ×10，不解析自由规格文字、不猜测未知单位、不先取整厘米。保留旧厘米显示字段时向上取整。
- 选择商品前再读取当前修订及真实商品状态/尺寸；可应用到当前模块，或同空间、同图例/自定义定义、同宽深/高度的全部模块。每模块一个确定性清单行，重复选择更新该行，不增加件数。
- 商品与真实变体、旋转、毫米规格、当时价格和清单行 ID 存入模块的 `productSelection` 快照；预留 `w/h/x/y/rotation` 保持不变。事务内保存新画布修订及清单，按项目行锁（2026-10-17 已由 [WORKSPACE-001](WORKSPACE-001-remove-project-info.md) 改为工作区事务 advisory lock）串行化画布写入；旧修订的延迟保存拒绝覆盖较新的商品选择。
- 请求先同步当前草稿；切换模块、改动排版或旧异步结果不能覆盖当前页面；失败和空结果不回退到演示产品。

## 接口与存储

- `POST /api/v1/office/projects/{projectId}/module-recommendations`：zoneId、moduleId、canvasRevision、allowRotation；返回实际预留、分档候选、同规格数量、缺尺寸数量。
- `POST /api/v1/office/projects/{projectId}/module-products`：上述字段加 productId（真实 variantId）、applyToSameModules；返回新画布、清单行和已选匹配。
- 服务端从项目最新已保存画布读取模块需求，不接受客户端自报需求宽深。推荐读取不创建商品选择；应用时重新核验。
- 复用 `office_canvas.objects_json` 和 `office_cart`，无新表/列或数据库迁移。旧通用清单接口和整体方案确认生命周期未在本任务重写。

## 验收边界

本轮是预留宽深与真实商品变体的尺寸匹配，不是完整品类、使用净距、门窗通达性或效果图验收。商品名称不能替代可靠品类字段；界面提示结合详情核对用途/结构。老清单和失效布局的商品引用保留；完整方案确认、历史清单迁移/失效管理仍属于 RECOMMEND-001/FLOW-001。无真实商品选择写入、数据库集成或真实识别验收。
