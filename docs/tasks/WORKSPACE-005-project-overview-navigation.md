# WORKSPACE-005 五入口导航与项目总览

基线为 `develop` 上的 `8589ea0`。本批实现 HTML 原型中的导航和工作台总览。

## 实施

- 顶栏提供项目工作台、产品库、空间设计、产品方案和项目清单。产品方案使用现有设计画布和复核门禁，按当前房间的排版确认状态打开产品选型或款式推荐。项目清单继续走原有路由守卫。
- `/workspace/project-bench` 保留项目列表。`?view=overview&floorId=…` 显示项目总览。`?floorId=…`、`?view=drawing` 和根路径继续支持图纸上传。创建项目后进入首层上传，已有项目从列表进入总览。
- 总览读取现有项目参考图、负责人及协作者和商品参考金额。项目资料更新只应用对应字段，保留列表接口返回的预算口径和其他项目数据。
- 楼层总览只读已加载的目标楼层草稿。房间面积复用空间测量，未知比例或无效轮廓明确显示待校准或待修正。已选件数复用清单门禁的有效家具关联校验。空间复核和排版确认分列。
- 概念效果图按当前楼层中选定的空间读取，每次最多展示四张已成功生成的结果，保留历史标记。切换空间或楼层时丢弃旧响应。当前楼层图纸仍从原上传入口管理。
- 原四步顶栏、重复的侧栏主入口和固定外链海报已移除。保留空间模板、项目树、历史导入记录、用户管理、账号菜单和侧栏宽度调整。

## 验证结果

- `pnpm build` 通过。构建仍报告排版工具重名自动导入、较大前端分块和依赖弃用警告。
- Edge 模拟接口通过 `pnpm e2e:workflows`、`pnpm e2e:project-floors`、`pnpm e2e:workspace-isolation`、`pnpm e2e:recognition-progress`、`pnpm e2e:account-center`。核对五入口、旧上传地址、保存需求保留预算、异形面积、选品计数、效果图归属、跨楼层跳转和清单门禁。
- `MOCK_API=1 pnpm e2e:smoke` 通过。空商品库模拟验证清单门禁会拦截，再打开标有演示数据的清单。
- 实看 1440px 和 390px 的总览截图，复测 390px 房间表五列在容器范围内。模拟页核对待复核房间跳到目标空间的核对入口。
- `git diff --check` 通过。真实服务联调和业务验收待执行，本批未涉及 Java、CAD 服务或数据库变更。
