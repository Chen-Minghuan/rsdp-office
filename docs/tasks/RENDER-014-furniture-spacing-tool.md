# RENDER-014 家具模块净距测量

从「AI 效果图 → 测量已保存的家具间距」读取当前空间的后端测量结果。结果按毫米记录逐件最近模块的边缘净距与中心距，并记录平行且中心对齐模块的相邻净距、贴合状态和连续贴合组。桌子共边时保留零净距。只有一点接触时，最近距离是零，仍不判为整边贴合。同类模块的前后边距只说明家具边缘距离，可用通道宽度仍要另外核对。

后端复用生图快照中的旋转、镜像和世界毫米占地。以轮廓边段计算最短距离，独立椅子实例参与测量，随工位图例绘制的示意椅位没有独立几何。生图前的只读接口沿用楼层授权，带方案确认 ID 时按确认快照核对。客户端拒绝与本地当前排版不一致的回包。新任务自动调用同一测量函数，保存于 `spatialControl.furnitureSpacing`，两种提示词均消费同一结果。白模引导图保留贴合模块的分缝。生成模型仍需输出核对，历史图和旧任务快照继续按原数据展示。

验证：Java 421 项，412 通过、9 跳过。合成的 5×4 阵列在 0°、37°、90° 均测得 15 对同排零间距、16 对前后 1000 mm。另覆盖镜像 L 型桌内角和仅角点相触。从本机一张 20 件效果图的保存快照只读回算，得到相同的组数和距离。前端构建与模拟效果图回归通过，回归覆盖当前测量有结果、未保存版本提示和测量不提交生图。未重新调用付费生图。
