# LAYOUT-025 通道宽度拖柄

状态：已实现并通过验证
更新日期：2026-10-22
负责人：按实际填写
基线/交付版本：工作区
关联：[LAYOUT-021](LAYOUT-021-canvas-aisle-channels.md)；[LAYOUT-024](LAYOUT-024-channel-selection-inspector.md)

## 目标与验收

触发：悬停/选中通道条带，拖拽其两侧边缘手柄。
结果：拖动实时预览宽度变化（含净距带），松手一次提交 `updateZoneChannels`；宽度钳制使禁放带不超出空间包围盒；Escape/pointercancel 丢弃。
范围：画布宽度拖柄；位置拖动与数值输入保持现状；吸附属 LAYOUT-026。

- [x] 验收项 1：拖 max 边只改宽度、拖 min 边位置与宽度联动（远端固定）、宽度最小 1mm 不翻转；提交后排版预览随动
- [x] 验收项 2：拖宽越界时钳制到包围盒边缘（含净距）；提交走 updateZoneChannels 获得撤销
- [x] 验收项 3：专项 e2e 断言 + 回归

## 现状与依赖

- 现状宽度只能在面板输数值；条带拖动模式（预览/提交分离、指针捕获、钳制）已就绪可复用。
- 与 LAYOUT-024 的选中态配合决定手柄何时显示（建议选中或悬停时）。

## 实施步骤

- [x] 扩展拖动模式 `channel-width`（记录初始位置/宽度与锚边），预览/提交分离
- [x] 钳制与提交路径（clampChannelWidthDelta，净距不变、禁放带不出包围盒）
- [x] 专项 e2e + 回归，更新文档
