# LAYOUT-014 用途匹配、分组排版与方案预览

日期：2026-10-20。状态：已实现并通过构建、算法、专项 UI mock 与 Java 测试；真实服务和建筑使用效果待验收。

## 目标

按用户认可的检查方案修复：会议用途与模块匹配；目标人数和桌椅组合；保留固定图例并增加自动推荐；重新排版保留手动家具；配置禁放/入口预留；画布预览与应用结果一致、变化原因明确。

## 实现约定

- 设计几何统一毫米。预览不写入已保存画布；应用重新核验当前空间与家具版本，单次撤销。
- 自动家具使用稳定分组标记；手动家具、其他空间保留。旧未标记实例只按明确的旧排版设置及同模块/会议上下文识别，不把手动家具猜作可删除内容。
- 人数由用户输入/确认；房名数字仅作建议。椅位和活动预留是可调整的规划参数，不代表法规或完整建筑通达性验收。
- 未知门窗/柱数据明确提示；用户可配置毫米禁放矩形。已有轮廓与已保留家具参与规划。
- 固定图例保持既有组合；自动推荐另比较方向、位置与候选排布，允许部分需求未满足但明确反馈。

## 验证计划

纯函数验证用途拦截、人数/桌椅组合、异形/负坐标、障碍避让、分组保留与方案比较；前端构建；专项 UI mock 验证预览不保存、应用/撤销/刷新/切换空间与确认状态。结果完成后补记，真实建筑及服务验收另记。

## 实际实现

- 会议室默认打开会议桌目录；选职员桌等非会议模块时禁止自动应用，并提供改用会议桌与逐件添加。辅助柜/椅/绿植不再隐式套用职员桌多排。
- 支持明确输入 0—500 目标人数；房名数字只供点击采用。默认会议桌生成实际会议椅，按椅子实例计人数，显示缺口。可显式按人数调整桌长，放不下时尝试容纳范围内的桌长并如实显示不足，不伪造 60 人容量；预览显示本次实际桌面尺寸。
- 固定图例保留原组合；自动推荐独立比较多排、面对面和中央通道候选（底层横纵比较），会议方案比较 0/90 度和多个候选中心。屏风推荐仍比较兼容的专用组合，不拆坏固定组合。属于确定性启发式，不保证全局最优或自动识别入口。
- 新生成家具保存 `layoutGroupId=auto:{spaceId}` 与 primary/seat 角色。重排只替换该组；旧未分组家具仅在有 layoutSettings 且模块相同、或会议室明确记录 meeting 上下文时作为旧自动组处理。其余全部保留并参与避让。旧错选且明确记录为会议自动组的职员桌可随本次方案替换；来源不明的不同模块不会被猜测为可删，可手动删除。
- 用户可添加多个入口/禁放矩形；界面输入相对空间左上角的毫米距离，存储为世界毫米。空间、家具、椅子朝向对应的拉椅活动区与禁放区共同参与检查。门窗/柱及连续通路未知仍提示现场核验。
- 待应用家具和活动区在现有画布半透明叠加；预览不保存、不取消已保存方案确认。应用时检查 sourceKey 并重新计算方案，避免旧预览覆盖更新。方案相同禁用重复应用；数量/尺寸/位置/间距/参数变化分别反馈。
- 应用清除本空间确认及旧自动组商品选择，其他空间保留；单次撤销恢复几何、需求、确认和关联选品。空间确认计数改为全体家具均确认。
- 前端确认与 Java 保存/推荐入口检查确认家具的轮廓包含、重叠、用途、预留区域、墙距、拉椅区和人数不足。非确认草稿允许继续编辑；未新增数据库表，沿用画布 JSON 保存可选字段。

## 边界

2026-10-20 最新要求覆盖：职员桌与屏风不再比较通用多排/中央通道候选，统一严格使用当前选中的参考图例，完整组合不可按目标人数截断；会议推荐继续保留。规则版本、件数与镜像详见 [LAYOUT-015](LAYOUT-015-exact-reference-presets.md)。本文件上方的多排推荐描述仅记录此前实施过程。

桌椅间距/座席间距为规划初值而非法规结论；复杂空间仍可能需要手调。L 型和屏风仍采用已有保守矩形占地，专有共享屏风几何按原任务推进。自动推荐不是所有家具类别的通用智能设计器。原全工作流、CAD 样本和现场通达性本轮未扩大验收。
