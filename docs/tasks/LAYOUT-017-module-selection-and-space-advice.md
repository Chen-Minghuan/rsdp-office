# LAYOUT-017 家具选择统一与空间用途建议

日期：2026-10-20。状态：已实现，专项验证通过；真实服务保存/回读待验证。

## 用户要求

任意空间均可选择任意家具，用途仅提供建议。取消“产品样式”与“单位模块”双重选择；直线桌不能选择 L 型产品样式，选择屏风卡位或排布方式不得暗中换家具或跳到参数页。

## 实现

- 唯一入口为家具模块目录，共 30 款；新增一字屏风卡位和 L 型屏风卡位的独立模块 ID。选择停留当前模块页，下一步由用户操作。
- 参数页只设置当前家具尺寸/间距；排布页只提供当前模块支持的方式。结构样式由模块和自定义模块的来源派生，名称不改变来源几何；应用时复核模块与排布兼容性。
- 职员直线桌/一字屏风提供单排与对坐；L 桌提供 L 单排与对坐；L 屏风提供 F/T/C/十字组合。沿用 LAYOUT-016 的场地自适应容量与完整组合。
- 其他家具支持单件居中或按场地排布，目标显示为件数；会议桌的目标为真实座位数。目标仍以 layoutPreferences.targetSeats 存储，语义由实际主模块 layoutContext（other/meeting/workstation）决定，前后端一致。
- 会议室初始推荐会议桌、目录优先显示会议类，但前后端均取消用途硬限制。刷新按已选模块恢复，旧屏风元数据在界面映射为显式屏风模块；应用前保留原对象。
- 保留毫米尺寸、边界/重叠/禁放区/座椅活动区检查、预览不落盘、替换自动组和撤销。

## 边界

本轮未重启正式业务服务或修改用户实际布局，未完成真实 API 保存/回读验收。空间用途不再限制家具；真实商品匹配及上下架规则仍在推荐阶段处理。通用家具按格网候选排布，不能保证异形房间的全局最优，入口、门窗和连续通路仍需现场核验。
