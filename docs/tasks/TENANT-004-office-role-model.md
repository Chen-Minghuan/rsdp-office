# TENANT-004 Office 角色、主号名额与授权

更新日期：2026-11-24

关联 [Office 数据库账号与权限关系](../office-database-roles.md)、[本地商品录入](INTEG-003-office-product-review.md)、[项目报价](QUOTE-001-project-quotation.md)

## 数据表

| 表 | 业务关系 |
| --- | --- |
| `office_user` | 登录账号。新增 `is_system_admin`，部分唯一索引限制全 Office 最多一人为管理员。沿用 `workspace_id` 记录成员所在工作区，沿用 `product_entry_enabled` 记录商品录入权。 |
| `office_workspace` | 经销商或工厂工作区，由 `owner_user_id` 绑定主号。新增 `dealer_slot_no`，编号唯一，范围 1–20。开户事务取可用编号。停用主号后工作区继续占用名额。 |
| `office_design_project` | 通过 `workspace_id` 归属工作区。楼层继承所属项目的权限。 |
| `office_project_member` | 按 `(project_id, user_id)` 记录负责人或协作者。新增 `permission_flags` 保存该成员在该项目中勾选的权限。 |
| `office_audit_log` | 保留成员和权限变更的操作者、对象、时间和修改前后记录。 |

系统管理员开设工作区和主号，维护账号状态和密码。经销商主号及工厂主号在各自工作区创建成员账号、选项目负责人、分配协作者和权限。`ADMIN`、`DEALER`、`USER` 继续用于现有接口兼容。平台移除单独创建普通账号的入口。

## 授权入口

| 入口 | 可配置权限 | 规则 |
| --- | --- | --- |
| 工作区账号 | 可录入商品 | 可独立授予本工作区成员。撤销后，已录入商品保留。 |
| 项目成员 | 查看、编辑、方案导出、成员管理 | 每个成员按项目授予。项目查看是其他项目权限的前提。成员管理可增减本区协作者。 |
| 项目成员 | 报价查看、毛利查看、报价导出 | 成员可访问已确认报价。毛利查看与报价导出依赖报价查看。接口及 Excel 按毛利查看权返回成本字段。 |

负责人和协作者的操作以主号勾选为准，新增成员默认无项目权限。主号负责指定负责人和更改授权。已获成员管理权的成员可以安排协作者，新增协作者的权限仍由主号配置。

以伟豪为例，系统管理员为伟豪开设一个工厂工作区和主号。伟豪主号可以让李工在总部项目查看、编辑并管理协作者，让周工只查看同项目和报价，为陈工开启本区商品录入。李工在其他项目的权限可以单独配置。

## 迁移和验收

迁移保留现有账号、工作区和项目 ID。既有管理员由历史 `ADMIN` 标识回填。工作区按创建顺序分配名额。历史项目成员一次性保留查看、编辑和方案导出，既有负责人保留成员管理。已部署环境若有多名历史管理员或超过 20 个工作区，须先确认现有数据，再应用新增数据库约束。

验证结果见 [当前进度](../status.md)。
