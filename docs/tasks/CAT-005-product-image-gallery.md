# CAT-005 商品图片展示与放大查看

## 目标

- 商品详情以适中的主图和缩略图展示全部可用图片，图片保持原始比例并完整显示。
- 鼠标移到详情主图时，显示局部放大镜查看细节；移到商品列表缩略图时，显示整张图片的大图预览。
- 保留详情页的资料编辑、图片添加和删除入口。

## 实现

- `ProductImagePreview.vue` 统一处理图片等比显示和悬停预览；详情使用局部放大镜，列表使用浮动整图预览，均通过页面顶层渲染以避免被滚动容器裁切。
- 商品详情调整为左侧适中主图与缩略图、右侧基础资料，规格报价移到下方；点击缩略图切换主预览图。
- 商品列表缩略图扩大到 72×72，并改为完整显示。
- 根据详情页复核反馈，移除主图上的“悬停放大查看细节”提示；主图、缩略图及悬停预览统一使用白色背景。
- 详情页调整为图片与基础资料并排、规格报价独立展示；只读资料直接呈现，编辑时切换为表单。主图按容器比例缩放，窄屏不裁切。
- 商品列表的图片、名称和编码共用一个商品详情链接；图片的悬停整图预览继续保留。

## 范围

本任务只调整前端展示和预览，不改变商品图片存储、上传或数据库数据。
