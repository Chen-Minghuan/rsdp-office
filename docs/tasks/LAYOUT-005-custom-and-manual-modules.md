# LAYOUT-005 自定义模块与逐件添加

状态：已实现并通过专项验证
更新日期：2026-10-15
基线：当前工作区，保留自动多排及实际应用状态修正。

## 目标与验收

单位模块可以自行新增：命名、复用现有办公家具图例、设置实际毫米宽深/可选高度，保存后复用。并补上逐件添加到画布：选择模块与规格，点击空间放置，可连续添加、旋转/结束，保留已有家具。

- 自定义目录在当前浏览器保存，刷新可恢复；界面明确保存范围。已摆家具携带独立模块快照，随现有画布 JSON 保存；目录后续变更不会静默改写旧实例。
- 沿用原毫米坐标、空间/模板 ID 和图例渲染；添加单件不替换已有布局，受影响布局确认失效，其他空间保持。
- 无效名称/尺寸/图例不得创建模块；放置越界/重叠不得写入几何；没有位置可用时不删除旧家具。
- 本轮不新增团队共享模块服务或自由绘制家具图例。目录为本机用户配置，已放置实例使用既有画布存储。

## 实现

- “＋ 新增单位模块”打开名称/共享家具图例/毫米宽深/可选高度表单，含实时线稿预览和名称/尺寸/重复名称校验；“我的模块 · 本机”提供选择、编辑、移除。
- `CustomOfficeModule` 使用稳定 UMOD ID 与内置 glyphTemplateId 分开；本机目录在 Office store 的 customModules 恢复时验证，保存范围在界面明确标识。配置变动不会改写画布家具或使原布局凭空变更。
- 新自定义实例携带独立 moduleSnapshot，旧实例始终按自己的名称、尺寸、图例与高度显示；即使目录被编辑/移除，或另一个浏览器没有目录，也能从已保存画布恢复。与实际商品仍分离。
- “添加到画布”开启逐件点击模式，指针显示有效/无效线稿预览；点击使用已有世界坐标逆变换，R/按钮旋转 90°，Esc/结束按钮取消，可连续添加。放置状态不写入持久化草稿。
- 独立 `officeManualPlacement` 模块校验旋转占地、实际多边形、离墙及已有家具间距；有效才分配 ID 和追加，保留原家具。成功后绑定当前空间模板并使当前空间家具排版确认失效，可撤销；不调用会切回总览的空间几何失效逻辑。
