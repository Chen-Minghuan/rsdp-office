# GEOM-007 空间轮廓自由变换

日期：2026-10-16。状态：已实现，构建与专项 UI 模拟验证通过；真实图纸与数据库集成验收独立记录。

## 目标

用户希望空间轮廓能像图形工具一样自由拉伸、放大缩小，不局限于改数值和逐点重描。保留 GEOM-006 未提交改动，继续使用现有空间几何和保存流程。

## 行为

- 默认“选择 / 缩放”：拖动内部平移；选中框八个控制点，拉边调整单轴、拉角调整两轴。锁定比例开关或按住 Shift 可等比拉角；对角/对边固定，不允许翻转穿越。
- 矩形和凹多边形均转换实际顶点，不以包围盒替代异形。包围盒只作为变换控制框，面积仍从多边形计算。
- “编辑轮廓”：拖动顶点、拖动整条边沿法向推拉、边中点补顶点，或使用既有沿墙重描。
- 中键/拖动画布及滚轮/缩放按钮仅改变视图。控制点维持屏幕大小，坐标经同一相机逆变换转换回设计坐标。几何手势期间冻结滚轮/按钮缩放，避免缩放改变拖动起点。
- 拖动期间显示预览及实时尺寸/面积，抬起提交一次；点击不改变几何。Escape、指针取消或窗口失焦恢复原稿；自交/退化轮廓不保存。
- 使用 `contourTransform.ts` 统一几何变换和 `updateZonePolygon` 保存；保留来源轮廓、底图、其他空间与单位，关联排版确认失效、模板标记过期，可撤销和刷新恢复。
