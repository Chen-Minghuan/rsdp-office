# LAYOUT-004 自动排版入口与实际结果

状态：已实现并通过专项验证
更新日期：2026-10-15
基线：当前工作区，保留已实现的毫米多排计算与旧家具数据。

## 问题与目标

用户截图中恢复了旧单排选择，画布仍为 3 件旧布局，当前单排预估为 2 件；此前主按钮按选中的模式执行，容易继续单排或误把预估当作已应用结果。

主按钮改为一键自动排版，显式执行自动多排，不受恢复的单排模式限制。单排/背靠背/矩阵/沿边保留独立应用入口。显示当前已放置和当前方式预估，位置/图例/尺寸变化也判断是否尚未应用，执行后显示真实生成数量；失败不得显示成功。

## 验收

- 恢复旧 row 设置与 3 件旧家具时，主按钮直接生成自动 3 排/6 件。
- 手动模式单独应用，刷新后仍可一键自动多排；预览不自动改动旧家具。
- 当前件数、预估件数与未应用状态准确，几何变化同数量时也识别；生成反馈取实际实例。
- 构建、专项/图例回归、冒烟与文档检查。

## 实现

- 主按钮“一键自动排版”固定执行 auto；显式手动模式使用“应用单排方案”等独立入口，恢复旧 row 设置不能限制主操作为单排。
- 同时显示当前已放置、当前方式预估及自动多排方案件数/排数。`furnitureMatchesPlan` 根据图例、宽深、旋转及实际占地位置比较方案，不能只比较数量；同数量拖动后显示尚未应用。
- 应用成功反馈使用实际实例件数；方案或几何改变后清除旧成功提示。失败结果不得显示成功。
- 参数内容可滚动，统计及主操作保留在底部；常见 1440×900 视口仍能直接看到主按钮。右侧说明及测试选择器同步新入口名称。
