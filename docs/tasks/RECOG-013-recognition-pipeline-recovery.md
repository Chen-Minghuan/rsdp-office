## 诊断证据

修复前相关 36 项 Java 测试全部通过，仍存在以下组合缺口：

- thin-partitions 原有候选包含 17 个多边形，其中仅 11 个获得墙线支持；清除初始 polygon 改为语义输入后仅保留 11 个，中央开放区无法恢复。不能把原有 17 个粗轮廓当作准确率。
- 独立定位不可用时，两张冻结实图的语义输入均得到 0 个轮廓。
- 6 间主管室漏一个独立文字框时，6 间全部失去墙线轮廓。
- 当前缺少工装墙体 ONNX 权重；该条件不通过代码回退伪装为已解决。

训练墙体模型、原图高分辨率推理、矢量 PDF 线段提取与跨图纸精度验收仍需独立完成。开放功能边界继续明确为估计。

## 实现与新发现

- `RoomLabelGrounding` 验证文字框、去重并合并位置；独立定位优先，仅补缺失位置。主请求新增紧框及逐字尺寸/面积文字，仍禁止输出房间边界。
- 同名分配允许缺失位，独立请求多识别的房名补为有来源的语义候选；定位完全不可用时另扫描保守封闭墙网，不强行给几何套房名。候选按来源 polygon 生成 ID，输入不被修改。
- 全量发现排除不足整图面积 0.3%、窄边不足最长边 2%、宽高比不足 0.2、页面泄漏、无效或与已有轮廓相交的区域。这些是保守候选策略，并非建筑规范；狭长未命名走道不保证检出。
- 主请求定位补位的轮廓明确为 low / contourGrounded=false；与独立定位原始响应分开保存。关闭独立定位开关不再关闭新语义响应必需的墙网生成。未配置分割模型时显式提示 Java 回退。
- 本轮真实 Qwen 返回女卫文字框偏左，落入隔间碎片，旧逻辑虽有印刷面积却因房名归属通过而跳过补救。本轮让与可靠相对面积明显不符的轮廓继续尝试现有弱线/隔间合并；仍不足预期面积 65% 或超过 135% 时拒绝提升为可靠轮廓。相对面积依据至少三个结构区域且 80% 的比值位于中位数 ±25%，不产生实际比例或毫米面积。
