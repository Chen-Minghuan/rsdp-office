# LAYOUT-007 常用排布与间距初值

状态：已实现并通过专项验证
更新日期：2026-10-16

## 需求与范围

在单位模块自动排版中增加常用方式，允许一键应用前调整桌子左右是否留缝、每列间距、排间净距和离墙距离。此前同排间距初值为 100 mm，本轮新布局默认改为 0 mm；已保存方案保留其原有设置，不自动改写家具。

## 实现

- 增加面对面、错位排、中间通道三个独立方案。面对面和背靠背分别保存面对净距/背靠中缝；中间通道使用排间净距作为中央宽度。
- 复核后固定各方式语义：单排贴上侧；背靠背指坐席朝外、双排背侧相接；面对面指坐席朝中央相对、默认 900 mm 面对净距；中间通道改为左右两侧桌列朝向中央连续通道；错位排相邻行错开；沿边先放上下侧，再用不重叠余量放左右侧。
- 自动优化仍比较横纵多排；新增参数与自动方案共用实时预估，只有点击应用才替换当前空间家具。
- 左右留缝默认关闭（0 mm），打开初值 100 mm，也可直接输入每列桌子的毫米间距。排间净距 900 mm、离墙距离 300 mm 保持原初值。
- 沿用多边形包含、离墙与防重叠检查。模式和间距随实例保存，刷新及撤销可恢复。原有方案内的 100 mm 设置继续生效。
