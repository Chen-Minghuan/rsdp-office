# LAYOUT-012 排版画布尺寸标注

状态：已编码待验证
更新日期：2026-10-17
负责人：Codex
关联：LAYOUT-001、LAYOUT-010、LAYOUT-011、GEOM-002

## 背景与目标

排版结果需要在单空间画布上直接表达实际毫米尺寸，帮助用户核对空间外接尺寸、模块规格、排布总长和排间净距。标注必须与当前空间和家具的世界坐标共用同一套变换，不能用屏幕像素估算。

## 实施范围

- 新增 `officeDimensionAnnotations` 尺寸计算模块：处理旋转家具的可见外包框、排版行分组、排间净距和毫米格式化。
- 单空间设计画布默认显示空间外接尺寸、每排总长、每个排版单元的实际宽×深；排间存在净距时显示垂直净距标注。
- 标注使用 SVG 世界坐标，与家具、空间、多边形、缩放和平移同步；标注层不拦截家具选择和拖动。
- 空间尺寸明确标为“外接尺寸”，避免把异形空间包围盒误认为净面积或精确墙边长度。

## 验收标准

- [x] 设计模式有尺寸标注层，且标注随画布缩放、平移和家具旋转保持对应。
- [x] 每个排版单元显示保存的实际宽×深毫米值。
- [x] 每排显示排版件数和总长；相邻排的非零间隙显示排间净距。
- [x] 异形空间使用外接尺寸措辞，不替代真实多边形边长或面积。
- [ ] 在浏览器回归中确认标注可见性、文本密度和拖动交互；当前环境缺少 Playwright 浏览器可执行文件。
