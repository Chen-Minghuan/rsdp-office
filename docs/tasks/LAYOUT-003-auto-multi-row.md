# LAYOUT-003 一键多排与空间利用

状态：已实现并通过专项验证
更新日期：2026-10-15
基线：当前工作区，保留此前空间核对、模板、单空间及家具图例改动。

## 目标与验收

当前默认“单排”只沿顶边布置一次，宽深未一起参与排数计算。改为默认自动优化：比较横纵朝向，以真实毫米家具尺寸布置多排、整体居中并保留可调排间净距/离墙距离/同排间距；单排、矩阵、背靠背、沿边仍可显式选择。

验收：约 4.4m 方形空间不再只生成顶部一行；预估与实际实例数量一致，数值参数影响布局，不缩放家具；轮廓越界及家具重叠候选排除；参数无效/无法放下不清空原布局；应用后可撤销和刷新，旧确认不沿用。

## 范围

仅单位图例排版路径使用新毫米计算模块。默认间距是可调产品初值，不是行业规范或出入口/消防合规结论；建筑层仍未知，完整门窗避让、通达性与正式方案校验另行推进。不修改用户现有布局，只有点击一键排版才应用新结果。

## 实现

- `officeAutoLayout` 独立计算毫米排布，自动模式比较横纵整体方向；矩阵使用多排，背靠背使用多组双排；沿边排除转角重复/重叠。
- 可调排间净距/离墙/同排间距，初值为 900/300/100mm；根据真实尺寸确定行列并居中摆放，空间不足不拉伸或缩小家具。
- 家具完整占地及离墙扩展范围必须包含于实际多边形；检测凹口穿过占地的情况，不能只看四角或包围盒。异形使用有限个朝向/对齐候选比较，保守处理 L 桌外包范围，不保证全局最优。
- 预估/应用调用同一模块，显示排数与朝向；单排仍显式保留并说明只布置一排。极端预计数量超过 2000 时明确提示，不静默截断。
- 实例保存 `layoutSettings`，刷新/撤销恢复模式、间距、图例及规格；预估不改原布局，点击应用只替换当前空间家具并取消该布局确认；其他房间/家具和原空间几何保留。
