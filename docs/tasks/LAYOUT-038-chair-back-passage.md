## 目标与验收

触发：前后排/相邻组椅子背对背时。
结果：椅背对椅背场景要求最小通行净宽（椅背伸出之外再留通行量，数值为可调策略值）；排版引擎排距不足时自动加宽到满足净宽（放不下则减少排数并说明），校核提示中明确说明自动加宽原因与数值；手动拖小间距时给出同级提示。
范围：排距/组距计算与提示；硬校验拒绝语义不变。

- [ ] 验收项 1：净宽口径与自动加宽规则定稿（含"加宽后放不下→减排+说明"）并有单测
- [ ] 验收项 2：自动加宽的提示文案说明原因与数值；手动编辑触发同级提示
- [ ] 验收项 3：专项 e2e + 排版回归；与 LAYOUT-035 分级体系对齐

## 现状与依赖

- 现状：椅子活动区有重叠/出轮廓校验；排距是固定参数，不做"椅背对背通行"自动加宽。
- 依赖：自动加宽改变排数与容量，需与目标人数校核、LAYOUT-034 候选评分口径一致。
