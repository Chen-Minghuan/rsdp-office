## 用户问题

截图中总经办三漏掉下方红框范围，总经办二的下边界也未延至墙内侧。需保留入口、退台及转角，不能靠规则矩形截断空间。

## 实现

- Qwen 识别提示要求连续追踪完整内墙边界、跨门洞延续墙线，避免以家具、洁具或文字作为房间边界；独立隔墙空间分别识别，不猜测合并。
- 核对画布“编辑轮廓”模式下，每条边中点可补转折点并继续拖动；原有矩形可以修正为凹多边形。
- “沿墙重描轮廓”允许在底图上顺序点出任意空间范围，含用户指定的附属区域；支持退回一点、保存、取消和 Escape。绘制期间旧轮廓不变，保存时核验重复点、自交及退化，首尾自动闭合。
- 复用同一相机反变换与 `updateZonePolygon`，已校准的毫米坐标和未校准来源坐标分别保留；不修改原始识别、底图与其他空间。保存后面积/范围从新多边形计算，原有排版确认及模板按既有规则失效，可撤销和刷新恢复。
- 重描时暂禁空间切换、属性修改、模板及排版操作，避免未保存的新边界被当成完成；不增加空间逐个确认门槛。
