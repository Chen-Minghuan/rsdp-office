# RENDER-002 单空间 Qwen-Image-3.0 概念效果预览

日期：2026-10-15。状态：实现完成，验证记录见下；真实方案视觉对应仍待业务验收。

## 用户要求与范围

用户明确只需二维图片，通过透视、光影和材质看起来具有立体感，并优先使用 `Qwen-Image-3.0` 实现。
新增排版后的概念预览入口，独立于正式方案效果图，不增加商品选择或方案确认前置。保留工作区既有商品推荐改动，不重写该模块。

## 已实现

- 单空间工具栏“效果预览”替换原仅放置参考素材的“效果图”入口；总览参考素材入口保留。
- 风格、鸟瞰/室内透视、补充偏好；真实异步等待、失败、重试、历史恢复和 PNG 下载。
- 默认 `qwen-image-3.0`，复用已有百炼密钥，可单独配置；使用原生异步图像接口，不替换视觉识别模型。
- 后端根据已保存的毫米多边形与家具位置/旋转绘制布局参考 PNG，提交参考图与清单；不会发送整层底图或其他空间。
- 后端核验版本和快照一致性、单位、轮廓、家具尺寸、ID、越界与碰撞；负坐标及凹多边形保留，家具旋转绕中心。
- 项目范围的数据库记录、不可变快照、同请求去重、本地图片持久保存；密钥不入库、不进入前端。
- 旧结果与原快照绑定，空间/家具/商品变化显示历史，不覆盖当前几何；仅缩放、便签和其他空间变化不使此图过期。
- 失败查询可恢复原任务；成功仅在图片下载并保存后记录，供应商临时 URL 不作为长期资源。
