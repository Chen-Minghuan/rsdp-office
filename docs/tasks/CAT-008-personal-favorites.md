# CAT-008 个人商品收藏

## 目标与范围

商品库采用宽屏完整管理卡：1536px 以上每行八列，1440px 保持五列，更窄宽度沿用原响应式列数；每件商品右上角常显主题铜色爱心，未收藏为轮廓、已收藏为实心。点击爱心打开方案 B 弹窗，显示商品摘要、默认收藏夹、用户自建分组、分组商品数量、多选、新建分组及取消/确定。

第一期只支持个人收藏：不预置办公/家私等业务分组，不提供项目共享收藏、独立收藏管理页、分组改名或删除。默认收藏夹与用户自建分组均持久化；同一商品可属于多个分组，空选择保存表示移出当前用户所有收藏夹。

## 数据与接口

`office_favorite_folder` 保存 `folder_id/user_id/name/is_default/created_at/updated_at`；同一用户分组名唯一，部分唯一索引保证每人最多一个默认分组。`office_favorite_item` 以 `(folder_id,rspu_id)` 联合主键防重，按收藏夹级联删除；`rspu_id` 仅弱关联 RSDP 商品，不建立本地商品外键，商品下架不自动清除收藏。

接口：

- `GET /api/v1/office/favorites/folders?rspuId=...`：当前用户分组、数量及商品已选状态。
- `POST /api/v1/office/favorites/folders`：创建当前用户自建分组。
- `PUT /api/v1/office/favorites/products/{rspuId}`：事务保存完整 `folderIds`，新增/移除关系并保留未变关系。
- `GET /api/v1/office/favorites/product-ids`：当前用户已收藏商品 ID。

用户身份只从服务端会话取得；保存时核验商品可见性与每个分组归属。前端使用独立 `FavoriteFolderDialog.vue` 与 `favorites.ts`，请求统一走 `useOfficeApi`，Heart outline/solid 复用现有 Heroicons 依赖。
