# TENANT-003 工作区账号中心

## 目标与范围

把侧栏中经销商主号专属的「商品报价」「工作区账号」两个独立入口合并到底部账号行，鼠标悬停账号行时展开单列直达菜单：

- 仅保留「商品报价 / 工作区账号」两个链接，分别进入对应完整页面。
- 当前项目存在最近确认报价时显示「最近」徽标；工作区账号显示在用成员数。
- 不显示浮层内的当前账号块、报价/成员/公共库预览或底部入口，侧栏账号行本身保持不变。

角色边界：只有经销商主号渲染悬停入口并请求工作区管理数据。系统管理员、项目负责人、项目协作者、设计师和普通成员不渲染该入口、不出现空面板，账号行保持原有显示与退出登录；管理员仍保留「用户管理」。后端既有经销商权限校验不因前端合并而放宽。

## 交互与实现

- 账号行悬停展开；移入浮层保持展开，离开后延迟收起。
- 点击「商品报价」进入 `/workspace/quotes`，点击「工作区账号」进入 `/workspace/users`。
- 点击账号行或按 Enter 切换面板，Esc 收起并把焦点还给账号入口；点击外部、焦点移出或路由切换时收起。
- 浮层固定在账号行正上方并左对齐侧栏，保留 8px 间距；监听窗口缩放、滚动及侧栏宽度变化，窄窗口下限制宽度，避免横向超出视口。
- 菜单徽标只在展开时加载最近报价和成员列表，不读取公共库或渲染预览；项目切换或路由变化后使徽标失效，下次展开重新读取。普通成员不会发起最近报价或成员列表请求。
- 前端改动：[AppSidebar.vue](../../frontend/app/components/AppSidebar.vue) 移除独立入口并传入经销商标记；[AppUserSession.vue](../../frontend/app/components/AppUserSession.vue) 实现悬停入口、预览和键盘行为。
- 未改动后端接口、数据库或既有报价/账号页面。
