# LAYOUT-043 原图参考与组合布局

## 工作流

多选功能模块后，组合候选按通行优先、功能分区和沿墙收纳比较。经理办公室供主管桌和高管桌比较。组合算法尝试横纵向、相邻墙边与多个摆位，在当前轮廓、建筑约束、启用布置区及通道内保留可行分支。普通需求最多保留三个部分布局分支，高容量探索有上限，结果不作为核准容量。

候选先比较办公工位或套数的缺口和功能覆盖，再比较入口到主要家具的采样通路、椅后与柜前净空，最后结合可选的综合评分。图层对照中没有标注门洞时显示入口待核验。家具占地比仅辅助比较。单模块原有三档候选仍可使用。

「参考原图摆位」在布局画布和右侧面板中操作。底图取当前楼层和分析版本的已存图纸，使用画布的毫米变换裁出房间；已校准 PNG、JPEG、WebP、PDF 或 CAD 的栅格预览可以作为来源。点击「识别原图家具」才向当前配置的百炼模型提交裁图。识别结果在画布上用与「产品选型」共用的家具图例显示，可点选和拖动，并在右侧换图例、旋转、确认和删除。可在画布点击放置预设规格的家具，并加入指定组。低置信度标记须经人工调整或确认才参与；额外功能在右侧明确纳入。

「应用当前方案」从参考编辑直接写入当前纳入的家具，使用当前坐标、尺寸和旋转。待确认的纳入家具或几何冲突会阻止整组应用并保留编辑状态。原图手工摆位校验实体重叠、空间轮廓、布置区、建筑约束和通道，自动组合的间距预设只用于自动组合。应用后实例记录分析 ID、版本及估计或人工确认来源。具体 SKU 仍在确认排版后绑定。

## 接口与校验

- `GET /api/v1/office/floors/{floorId}/layout-reference/source?analysisId=…&revision=…` 返回有访问权的当前图纸栅格。
- `POST /api/v1/office/floors/{floorId}/layout-reference/recognize` 接收同一分析版本和 PNG 裁图，返回裁图归一化家具框、方向、分组和置信度。沿用 `DASHSCOPE_API_KEY` 和现有视觉模型配置。
- 新组合记录 `layoutPreferences.mixed.spacing` 与家具 `mixedBundleId`。离墙、不同功能组间的组合净距和距保留家具净距在生成、拖动提示、应用、确认和 Java 保存核验中使用相同口径。已保存的历史布局沿用原有校验。
- 通路和椅后／柜前活动区是候选比较和现场复核指标。采样宽度为策略值，精确建筑通行另行核验。

- 前端构建 `pnpm build` 通过。
- 算法 `pnpm test:mixed-layout`、`pnpm test:layout-planning` 通过。
- UI mock `pnpm e2e:preview-drag`、`pnpm e2e:layout-planning`、`pnpm e2e:module-recommendations`、`pnpm e2e:workflows` 和 `MOCK_API=1 pnpm e2e:smoke` 通过。首次专项含原图识别预填、低置信度结果人工确认、补录额外家具、越界预览拦截和应用快照。
- Java `mvn -f backend/pom.xml test` 共 275 项，272 通过、3 跳过。
- 文档相对链接和 `git diff --check` 通过。

原图参考改为画布内操作后，重新通过前端构建、两组算法、`e2e:preview-drag` 和 `e2e:layout-planning`。专项验证参考面板无弹窗、预设图例、按毫米拖动、点选低置信家具、点放柜子、候选写入；UI 仍使用模拟 API。

参考摆位接入共用的画布拖动和放置预览，「吸附」控制 50 mm 范围内对墙和家具边线对齐，移动时显示引导线。选中家具后通过共用旋转和删除入口处理 `R`、`Delete`、`Backspace` 和画布动作按钮。放置前可按 `R` 调整朝向。

本轮前端构建、`e2e:preview-drag`、`e2e:layout-planning`、`test:furniture-snap` 和 `test:mixed-layout` 通过。UI 使用模拟 API，覆盖拖动吸墙、点放吸墙、引导线、快捷键旋转删除和画布旋转按钮。

参考摆位改为直接应用后，前端构建、`test:mixed-layout`、`e2e:preview-drag`、`e2e:layout-planning` 和 `git diff --check` 通过。专项 UI mock 验证待确认和重叠时留在编辑状态，成功时一次应用、无候选切换、原样保留移动后的办公桌和旋转后的柜子。

已应用的家具在画布单击后打开「产品选型」并滚动到该件的尺寸编辑区。宽深仍按家具本地方向输入，改尺寸时保留旋转后外包占地的左上锚点，校验当前家具与空间边界、约束和其他家具，成功后将本空间排版置为待确认。专项 UI mock 覆盖从已确认排版直接打开详情、90° 贴墙柜从 1200 缩到 1000 mm、越界拒绝和确认失效。
