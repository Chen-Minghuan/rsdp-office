# PERF-002 Office 批量查价和商品库分页

2026-11-24 实施第三步。Office 空库按启动脚本复核为 23 张表。

## 接口和权限

- 预算服务从当前账号有权访问的楼层购物车提取去重后的有效规格 ID，向 RSDP 按每批最多 50 个 ID 查询零售价。不可见、下架或缺价的规格按待补价处理，批量服务故障按不可用处理。批量结果按目录权限和规格批次隔离缓存 30 秒。
- 商品库将页码、每页数量、关键词和状态发给 Office。RSDP 按授权范围计数，在数据库完成名称、RSPU 编码、外部型号或 RSPU ID 的字面匹配和分页。同一创建时间按 RSPU ID 继续排序。共享视图展示在售商品，关闭共享库后只有绑定工厂可读取其归属商品。分页最多 100 条。
- 报价试算、确认和草稿导出批量读取所选规格的品名、规格和主图，出厂价和授权仍走原 RSKU 与 Office 项目权限。确认版本、手填价格、费用和 Excel 逻辑沿用原实现。浏览器商品库使用分页，设计推荐仍使用独立的设计目录。
- RSDP 后端发布新增目录接口后，Office 自动启用批量查价和上游分页。滚动发布期间，Office 确认新接口缺失后短暂沿用旧目录读法，在 Office 内完成分页，约 60 秒后重试新接口。旧目录的本厂范围只接受 RSDP 明确核验为本厂归属的商品。权限拒绝和新版接口故障按原错误处理。两端本次变更不需要数据库迁移。

## 冷热对照

上一轮同一只读 RSDP 测试目录的 185 个商品和相关规格、报价在隔离 RSDP PostgreSQL 中重建，两版 Office 使用同一份含 3 个授权项目的本机数据库副本。前后端请求走同一台机器上的 Java 服务。冷预算取目录或批次缓存失效后的第一次 HTTP 请求，热值为 6 次中位数，Office SQL 通过 `pg_stat_statements` 统计。商品列表每次请求服务器，重复读表示连接和数据库热读。以下时间对应本机同环境对照。

| 接口场景 | 前两步版本 | 第三步版本 |
| --- | ---: | ---: |
| 冷预算 | 301.44 ms | 23.98 ms |
| 热预算 | 10.94 ms | 6.52 ms |
| 冷预算 RSDP 请求 | 232 | 1 |
| 冷预算累计 Office SQL 执行 | 0.230 ms | 0.255 ms |
| 商品列表首读 | 17.54 ms | 13.00 ms |
| 商品列表重复读 | 18.01 ms | 11.91 ms |
| 商品列表响应大小 | 92,965 B，185 条 | 10,115 B，20 条 |
| 浏览器冷预算金额可见 | 545 ms | 223 ms |
| 浏览器热预算金额可见 | 135 ms | 112 ms |

三个项目的预算金额和状态逐项一致。报价试算响应去除时间戳后前后完全一致，最终试算追踪只出现规格资料批量调用或已授权的 RSKU 读取。

## 验证

- 隔离双服务验证分页首尾、页间稳定去重、中文与特殊字符搜索、在售和非在售计数、非绑定目录、公共库切换、规格批量大小限制和目录账号权限上限。真实浏览器验证新分页的前两页和中文搜索，并通过请求记录确认页面只读取请求页。
- 真实 Office API 验证成员只能读取获授项目预算，跨工作区无法读取预算和报价，撤权即时生效。主号试算、草稿 Excel 导出、确认和回读通过，非毛利授权成员的 JSON 与 Excel 均裁剪成本。
- Office Java 353 项和 RSDP Java 2268 项通过，无失败或跳过。Office 前端生产构建通过。商品工作流、报价、项目楼层、工作区隔离、账号中心及收藏页面通过浏览器模拟 API 回归。
- 本次仅在隔离服务中运行验收。远程测试环境提供只读数据样本。
