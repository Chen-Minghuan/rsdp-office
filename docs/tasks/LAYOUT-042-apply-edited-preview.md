# LAYOUT-042 应用手动调整后的排版预览

状态：已编码待验证
更新日期：2026-11-15
负责人：Claude
基线/交付版本：工作区
关联：LAYOUT-034、LAYOUT-036；产品需求第 6 章

## 目标与验收

触发：用户在单空间自动布局中生成候选，拖动预览家具后点击「应用当前方案」。
结果：应用结果逐件采用当前预览的位置、尺寸、旋转和模块数据，不重新求解或回退到自动坐标。
范围：单模块与组合布局共用预览提交和失效逻辑；保留来源版本、硬约束、撤销和清单处理。候选生成算法不在本任务调整。

- [x] 空空间及已有排版上，单模块预览拖动后应用，最终几何与预览一致（模拟 UI 专项）。
- [x] 组合布局保持同样语义；未应用预览不写入正式家具。
- [x] 过期来源或最终硬约束冲突被拒绝；应用后确认失效且可一次撤销（过期/撤销由排版规划专项覆盖）。
- [x] 手动调整状态可见，未应用预览不能绕过应用直接确认。
- [x] 相关纯函数/UI 回归、构建和差异检查按实际结果记录。

## 现状与依赖

单模块原路径在 `applyLayoutProposal` 中重新调用 `planTieredLayoutProposal`，再按临时家具 ID 回填预览坐标；组合布局则合并当前预览后直接提交。两条路径重复维护替换自动组、清单扣减和确认失效逻辑，且既有拖动专项只覆盖组合布局。

## 决策与过程

| 日期 | 发现/决定 | 原因或证据 | 对下一步的影响 |
| --- | --- | --- | --- |
| 2026-11-15 | 应用以当前预览为几何事实来源，不再重跑求解器 | 避免重算与临时 ID 映射丢失用户编辑 | 求解器仅负责生成/切换候选 |
| 2026-11-15 | 单模块和组合布局统一 `applyLayoutProposal(zoneId, proposal, preferences)` | 删除 `applyMixedLayoutProposal`、候选索引和位置覆盖参数，共用替换/清单/失效逻辑 | 新增预览类型 `LayoutPreview`，不再重复声明内联结构 |
| 2026-11-15 | 应用前校验最终预览几何，成功后退出单模块预览 | 非法手动位置不能保存；手动结果与原始自动候选不同，不能继续叠加旧预览 | 未应用预览时确认入口明确提示先应用 |
| 2026-11-15 | 首次单选功能品类在 `nextTick` 后选择模块 | 子面板由条件渲染创建，立即访问 ref 可能为空 | 首次选择稳定开启预览 |
