# FLOW-003 方案确认工作台

日期：2026-10-19。状态：已编码，完成楼层→类别→空间的首版界面预览，等待用户确认信息层级与视觉方向。

## 目标

参考 `rooom2.0界面设计.pdf` 的空间级方案确认板，把最终确认从单一报价表调整为分层确认工作台。页面按“楼层 → 空间类别 → 具体空间”组织；具体空间下查看需求描述、平面布局、商品清单、效果图状态和客户批注，点击任一模块打开右侧详情抽屉。

## 首版范围

- `/proposal` 保留现有真实 store 数据，按同一张户型图推导楼层，再按空间类别聚合具体空间、家具、商品数量和金额。
- 页面内容不再绘制演示商品图和固定示意布局：商品清单优先使用商品资料的 `imageUrl`，平面布局使用前一步实际空间多边形与家具排版坐标，效果图读取该空间已有的效果预览任务和真实图片。
- 页面外层内容区启用纵向滚动，长方案可以完整查看所有楼层、类别和空间。
- 同一张图纸识别出的空间自动归入同一个楼层；类别示例为“1楼办公空间”“1楼会议空间”“1楼公共空间”。类别可以展开或收起，类别下的“会议室1”“会议室2”等具体空间可以逐项切换。
- 具体空间详情板按预设截图固定为五列：左侧大面积蓝色需求描述、中间左侧平面布局与备注、中间四列商品图片网格、中间右侧三个纵向效果图槽位、最右黄色客户批注；五列均可点击进入对应详细信息。
- 支持 `?preview=1` 查看不写入草稿的演示数据，方便先确认页面结构。
- 右侧摘要保留空间确认计数、商品数量、参考金额、方案状态、导出和返回入口；页面主体不再重复展示顶部整体统计卡。
- 同一空间内相同商品合并为一个商品卡，数量以“× N”展示；商品明细使用居中简约弹窗，不再从右侧抽屉滑出。
- 具体空间支持单空间确认，楼层下的空间类别支持一键确认整个区域，右侧仍保留整体方案确认。
- 排版平面卡片和详情弹窗使用前一步保存的家具排版坐标、尺寸、旋转和家具图例；原始户型图只作为识别底图数据，不作为排版详情展示。
- 平面模块展示当前空间的排版平面效果（空间轮廓、家具坐标和旋转），不再把整张原始户型底图当作缩略图。
- 商品详情展示 Variant、毫米尺寸、数量和参考小计；旧厘米字段展示时转换为毫米。
- 效果图模块展示当前状态和后续快照依赖提示，不启动自动排版或正式生图。
- 方案确认按钮当前只更新界面预览状态，正式方案快照接口待后续接入。

## 视觉解析

PDF 的主要信息关系是“楼层/类别 → 具体空间 → 需求/布局/商品/效果图/批注 → 状态确认”。首版采用暖白背景、棕色主色、绿色已确认和黄色待确认；类别头部使用红色楼层标识、灰色类别名称条、面积/金额/商品数量和确认状态，类别下使用缩进空间行。详情板严格按预设五列展示：蓝色需求面板占满高度，平面图面板下方保留备注框，商品面板使用 4 列网格，效果图面板固定 3 个纵向槽位，黄色批注面板占满高度。顶部项目流程与右侧摘要保留，使空间状态和金额始终可见。
