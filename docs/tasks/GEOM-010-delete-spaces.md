# GEOM-010 删除不参与排版的空间

日期：2026-10-17。状态：已实现并通过构建及专项模拟回归，真实持久化删除待业务验收。

## 行为

用户可在空间属性中直接删除当前空间，从列表与画布移除，同时移除该空间归属的家具、附属对象和选品清单，清除当前模板与已提交方案，支持撤销。删除当前设计空间时返回总览；其他空间保留。删除操作不再弹出确认框。

删除最后一个空间保存 `blank=true`，刷新带 analysisId 的页面也不会自动重新导入已删除房间。原始识别记录保留。保存状态显示同步中或失败，避免请求失败仍显示已保存；同步状态不写入本机草稿。
