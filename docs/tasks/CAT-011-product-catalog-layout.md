# CAT-011 产品库布局重排

本批落地 [五入口导航后的产品库布局](WORKSPACE-005-project-overview-navigation.md)，沿用原型的中间筛选与商品网格、右侧收藏结构。

## 实施

- 分类路径和主色使用商品列表已返回的 `categoryPath`、`colorPrimaryName`。选项来自当前授权目录，可与名称／编码及在售状态筛选组合，修改筛选回到首页。目录切换时清理已不存在的选项。缺少字段的旧商品继续包含在「全部」。
- 商品网格随实际中栏宽度切换列数，保留等比图片、价格与在售状态。每张卡片保留一个商品详情入口、独立的项目收藏与个人收藏按钮。移除已无入口的详情弹窗和重复详情链接。
- 右侧按个人或当前项目查看当前目录内的收藏，复用已读取的收藏 ID 及授权商品列表。点击「调整」继续使用原收藏弹窗，收藏中心打开对应页签。无项目时默认个人收藏。窄屏收藏区可展开，打开后将焦点移入收藏区。
- 公共库开关、本厂商品、主库商品维护入口、分页和收藏保存协议继续沿用，Java、主库与数据库均无新增契约。

## 验证

- `pnpm build`、`git diff --check` 通过。构建仍报告既有排版模块重名自动导入、大分块及依赖弃用警告。
- Edge 模拟接口下，`pnpm e2e:workflows`、`pnpm e2e:favorites-page`、`pnpm e2e:workspace-isolation`、`pnpm e2e:project-floors` 及 `MOCK_API=1 pnpm e2e:smoke` 通过。覆盖组合筛选及重置、缺图片状态、详情入口、收藏侧栏与弹窗联动、无项目时独立浏览和原有项目隔离。
- 核对 1440px 桌面与 390px 触屏模拟页面截图，确认大屏各区域可读、窄屏展开收藏可用。同时模拟带图商品，验证读图、悬浮预览和点击详情。真实目录和会话业务验收待执行。
