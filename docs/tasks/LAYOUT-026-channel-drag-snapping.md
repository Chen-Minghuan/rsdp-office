# LAYOUT-026 通道拖动吸附

状态：已实现并通过验证

负责人：按实际填写
基线/交付版本：工作区
关联：[LAYOUT-021](LAYOUT-021-canvas-aisle-channels.md)；ce2f9e9 家具贴墙吸附

## 目标与验收

触发：画布拖动通道条带。
结果：接近吸附目标时吸附并显示对齐参考线；远离目标时自由拖动；吸附不改钳制语义。**实施取舍**：吸附目标为墙边、家具占地边缘与其他通道禁放带边缘（复用 `snapFurnitureEdges` 的边吸附语义），未做"家具间隙中线"——边吸附与家具吸附手感一致且实现零新规则；阈值沿用家具同一 50mm 固定毫米值（不随缩放换算），与既有吸附体验一致，偏差在此记录。
范围：通道位置拖动吸附；宽度拖柄吸附可顺带；家具吸附逻辑不改动。

- [x] 验收项 1：拖向墙边在 50mm 阈值内吸附到墙缘（禁放带含净距贴墙）；家具边缘/其他通道边缘同一机制
- [x] 验收项 2（调整）：阈值固定 50mm 与家具吸附一致，吸附后可再次拖离（每次 pointermove 重算，不粘性锁定）；缩放换算阈值未做（与家具吸附保持同一取舍）
- [x] 验收项 3：专项 e2e 断言 + 回归
