# RECOG-004 原图墙线约束

日期：2026-10-16。状态：已实现，当前底图专项核对通过；未完成跨样本验收。

本文保留 V1 实现与当时验证记录。当前 V2 已改为独立房名检测定位（会额外调用一次模型），并支持同图人工轮廓继承；最新行为和未解决的开放分区问题以 [RECOG-005](RECOG-005-label-grounding-and-correction-reuse.md) 为准。下述“不增加模型请求”和按类型限制仅描述 V1。

## 用户问题

总经办一/二的轮廓没有沿间隔墙及底墙，总经办三被截断，漏掉下方凹入区域。GEOM-006/007 提供人工编辑，本任务改善新识别的自动轮廓。

## 实现

- 初次 Qwen 识别提供名称、类型及粗略位置；后端从同一标准底图提取横纵墙体笔画，连接短的同线墙体缺口，再从候选内部寻找封闭区域、沿内部边界生成多边形。整个过程不增加模型请求，不修改标准底图。
- 仅尝试有名称的总经办、会议室、厨房/茶水间、卫生间和书房等封闭房间类型；开放办公、未知类型和未命名候选保持原样。它不是通用矢量解析器，也不替代 CAD 服务。
- 分析最长边限制为 2048 像素，输出按实际分析宽高回算到标准底图归一坐标，适配器继续转换为来源像素；不据此猜测毫米、面积或校准结果。
- 较粗短笔画和较长细笔画分别提取；细外立面与短退台恢复单独处理。补门洞仅使用原始墙体笔画，不使用恢复的柜体/细线，也不使用另一方向刚生成的补线，避免在靠墙柜体与底墙之间填出虚假台阶。
- 当前策略针对轴对齐图纸：暗度阈值 185/215（墙体/细线）、墙体至少 3 像素厚；短笔画还需多数有 4 像素厚度支持，薄笔画长度至少为长边 7%。门洞补线最大为分析长边 5.3%（至少 30 像素）。细外立面恢复限图下部 35%、横向暗笔画覆盖页宽至少 65%；这些是图像启发式，不能视为物理墙厚或门宽标准。
- 区域触页边、过小/超过页面 40%、边界过复杂、自交、面积与像素区域偏差超过 5%、多个名称落入同一区域时不采用。与原候选不相交、面积比不在 0.25～4、新吞入其他封闭候选中心时同样保留原候选并提示复核。
- `initialModelOutput` 保留初次输出；`modelOutput` 为进入适配的结果，`contourRefinement` 记录方法、分析大小、每个候选采用/未解决状态与原因。门洞连接属于估计，始终保留复核提示，不自动标为人工确认，不要求用户逐个确认。
- 默认启用 `RSDP_VISION_REFINE_ROOM_CONTOURS=true`；可设 `false` 跳过。仅影响直连 Qwen 的新整图识别，单独尺寸识别、CAD 和外部识别服务不变。不覆盖用户现有设计副本。
