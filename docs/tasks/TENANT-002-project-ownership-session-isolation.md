- 保留历史项目 `OFFICE-PROJECT-001` 及全部画布修订，明确工作区和项目成员，不再让旧项目对所有人不可见。

- 不给系统管理员增加全网项目权限；管理员继续只负责账号和工作区管理。

## 前端契约

- `workspace.projects` 只保存服务端返回的真实项目。空列表显示“暂无可访问项目”；401/403/网络错误显示真实错误和重试，不伪造项目。
- 没有真实 `currentFloorId` 时显示统一空状态，不进入上传/画布/预算页面，也不调用项目画布 API。
- 登录成功和退出登录都重置 workspace/office Pinia 状态；项目和画布初始化校验请求发起时的用户作用域与楼层，过期响应不得覆盖新账号。
- 认证开启时缓存键包含服务端会话用户 ID：项目选择、画布 localStorage、识别 sessionStorage、效果图待提交参数及 IndexedDB 文件记录均隔离。
- IndexedDB 数据库名保持 `rsdp-office-files`，记录键改为 `用户 ID:楼层 ID:图纸 ID`；读取旧记录时复制到当前用户键，不删除旧原图。
- 旧未分账号的默认项目 localStorage 仅允许当前项目负责人（本次为 `dealer1`）迁移一次；协作者和其他账号不自动继承。服务端画布修订高于本地时仍以服务端为准。
- 认证关闭的纯开发模式保留原有缓存键，避免把不存在的登录用户强加给本地工具链。
