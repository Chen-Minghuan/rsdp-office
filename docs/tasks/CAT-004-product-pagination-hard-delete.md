# CAT-004 商品列表分页与批量永久删除

## 目标

- 商品列表支持输入页码跳转和选择每页展示数量。
- 商品列表支持勾选当前页商品并批量删除。
- 删除商品时物理删除商品主档、规格、图片、工厂报价、风格/场景关联以及购物车引用，不使用逻辑删除。

## 实现

- 前端 `products/index.vue` 增加每页 12/24/48/96 条选择、页码输入、当前页全选和批量删除确认。
- 前端 API 增加 `DELETE /api/v1/products/batch` 调用；商品详情删除成功后返回商品库。
- Java 商品服务新增批量删除服务方法，主档 Mapper 使用 PostgreSQL 数据修改 CTE 按外键依赖顺序物理删除关联数据。
- 保留旧恢复接口以兼容已有客户端；新删除不产生可恢复的逻辑删除记录。
