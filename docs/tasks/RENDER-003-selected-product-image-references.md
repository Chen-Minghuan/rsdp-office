# RENDER-003 效果图使用所选商品图片

日期：2026-10-20。状态：实现与专项验证通过，真实模型视觉验收待验证。

## 原因

模块选品已把 productId 和 productSelection 写入家具，效果预览快照也保留了它们；但原服务仅提交一张后端绘制的平面占地图，提示词仅有模块名称与坐标，没有读取商品照片或建立家具/照片对应。因此应用选品不能使旧生图链路还原所选款式。

## 修改

- 生图前按家具 productId 从后端当前可用商品目录核验真实规格及图片，不信任客户端传来的商品照片路径；productSelection.product.id 不一致时阻止提交。
- 读取本系统 uploads/images 下的商品库图片，支持导入/上传所存的绝对公开 URL 和相对路径，实际读取本地文件，不请求 URL 主机。校验根目录、真实路径、文件大小和像素范围，解码时降采样；照片缺失、格式不可读或商品失效均在调用生图前提示，不静默忽略。
- 同商品多模块去重成一张参考照片，P编号映射到布局家具清单序号，提示词区分图1布局与后续商品板；优先保留照片中的结构、材质和颜色。最多 24 种商品，分为最多两张参考板，与布局合计最多三图；超出时明确提示，不截断选品。
- 商品参考板与原图摘要、商品/规格、家具序号、版本一起绑定不可变任务。元数据存于已有 snapshot_json 的 renderProductReferences 字段；响应时将其单独暴露为 productReferences，snapshot 仍保持前端几何投影契约，不因服务端参考附件误报历史。
- 页面显示已绑定商品数、任务是否实际使用商品图片和参考板；旧任务不会被冒充为已使用商品图片，提示重新生成。未选商品的概念预览仍可生成；重复请求与查询不会重新收费提交。

## 验证

前端构建、效果预览 UI mock 通过；UI 覆盖所选商品随快照提交、商品图片标记/参考板显示及旧任务提示，并保留等待/刷新/历史/下载/失败/幂等回归。
Java 测试覆盖图片内容进入参考板、去重与序号映射、无选品/商品失效/伪造绑定/缺图阻断、路径限制、13种商品拆板、实际提供商 HTTP 请求携带多图、快照与附件隔离、原有异步/幂等保护。最终总数见补记。

## 边界

当前仍为概念效果图；把实际照片送入模型不等于完成商品外观与空间精确一致验收。未调用真实收费生成，未重启正在运行的后端，也未修改用户现有任务或效果图；部署新版并重新生成后才使用新链路。只读取本系统商品图片，外部独立图片链接需要先入库；不可解码图片需补充 PNG/JPG。参考板为主图，未新增变体专属照片能力。

接口依据：[Qwen-Image 3.0 官方文档](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)，2026-10-20 核对 3.0 系列支持 1—3 张参考图及原生异步 content 数组。

验证补记：Java 全量 166 项（163 通过、3 项数据库环境未配置跳过），最终幂等兼容调整后相关 18 项再次通过；前端构建、效果预览 UI mock 通过，已查看商品参考板入口截图。188 个本地文档链接和 git diff --check 通过。未将 mock 返回或合成测试色块称为真实模型外观验收。
