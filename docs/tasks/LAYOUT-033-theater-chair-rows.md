## 目标与验收

触发：培训/多功能空间不要桌子或只要前排桌子。
结果：支持「剧院式」纯椅排布局：前 N 排配桌（0–N 可调）、其后纯椅排；椅子可选联排（密排默认）或独立（左右/前后间距自定义）；有椅必有桌约束明确（配桌排内椅子不悬空）；容量与确认校验同步。
范围：椅排作为排版单元的引擎支持；椅子是否绑定商品变体沿用既有推荐链路。

- [ ] 验收项 1：纯椅排与桌椅混排的预览/应用/确认链路打通
- [ ] 验收项 2：联排/独立椅子间距参数定稿；「有椅必有桌」约束有单测
- [ ] 验收项 3：专项 e2e + 回归；容量统计口径与座位数确认一致

## 现状与依赖

- 现状：排版单元以桌/工位为主，椅子随桌生成；无独立椅排概念。
- 依赖：确认校验的座位统计（targetSeats）需覆盖纯椅排；与 LAYOUT-037 宽桌双侧坐人的容量语义相互影响。
