## 目标与验收

触发：会议/培训类空间选择 U 型或回字型排布。
结果：新增 U 型（三边坐人）与回字型（四边坐人）布局模式；回字型横竖排边缘对齐（两侧竖排端头顶住横排内缘，不只边角相交）；「回型面对面间距」可调（0=自动）；座位朝向规则明确（U 型无背对焦点侧；回字允许单边背对）；确认校验沿用轮廓/重叠/通道既有规则。
范围：排版引擎新模式 + 面板入口；不含讲台/朝向焦点概念（是否引入需业务确认，见参考文档）。

- [ ] 验收项 1：U 型/回字型预览/应用/确认链路打通，容量与间距参数明确
- [ ] 验收项 2：边缘对齐与面对面间距语义定稿并有纯函数单测
- [ ] 验收项 3：专项 e2e + 排版回归；通道/禁放区避让复用既有语义

## 现状与依赖

- 现状：布局模式为课桌式网格变体、沿边、中央通道、会议单桌居中、自适应参考拓扑；无 U 型/回字。
- 依赖：与通道切段（021）、边缘补位（020）共存规则需在任务内定稿。
