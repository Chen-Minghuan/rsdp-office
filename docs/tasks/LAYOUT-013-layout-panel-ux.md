# LAYOUT-013 排版面板操作体验

状态：已编码待验证
更新日期：2026-10-17
负责人：Codex
关联：LAYOUT-010、LAYOUT-011、LAYOUT-012

## 背景与目标

原排版侧栏同时展开模块目录、产品样式、排布方式、尺寸和间距，窄侧栏中需要连续滚动查找，应用、逐件添加和清空也形成多个同权重按钮。本次将操作收束为明确的三步流程，减少视觉拥挤并保留原有排版能力。

## 交互方案

1. 顶部使用“模块 / 参数 / 排布”三步导航，当前步骤高亮，并在下方显示当前模块和产品样式摘要。
2. “模块”步骤只处理目录选择和自定义模块；“参数”步骤先处理模块毫米尺寸和空间间距；“排布”步骤最后处理产品样式及图例排布。
3. 排布步骤提供当前模块快捷卡片，点击即可回到模块步骤更换模块。
4. 底部固定为当前/预估件数摘要、一个主应用按钮，以及“逐件添加 / 清空排版”次操作；确认排版单独保留为状态按钮。
5. 保留已有 `data-testid`、按钮文案语义、规则默认值和布局保存契约，界面调整不改变排版算法。

## 验收标准

- [x] 三步导航可在不丢失当前选择的情况下切换。
- [x] 默认从模块步骤开始，完成模块和参数后再进入排布步骤；尺寸或间距变化时，已应用方案标记为待重新应用。
- [x] 当前模块、样式、预估数量和应用入口在不滚动的情况下可见。
- [x] 模块目录、尺寸编辑、间距编辑、逐件添加、清空和确认操作仍可用。
- [ ] 浏览器视觉回归确认不同窗口宽度下的滚动、文字密度和按钮可达性；当前环境缺少 Playwright 浏览器可执行文件。
