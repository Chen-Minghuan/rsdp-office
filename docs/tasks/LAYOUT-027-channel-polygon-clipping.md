## 目标与验收

触发：L 型/凹形空间中添加通道。
结果：条带渲染与禁放带按房间多边形裁剪（缺角处不再画出轮廓外）；裁剪可能把通道分成多段矩形，排版切段与确认校验使用裁剪后几何。
范围：通道几何裁剪；禁放区多边形裁剪若需同做，抽公共裁剪模块，否则留边界说明。

- [x] 验收项 1：凹形空间通道条带不画出缺角；裁剪后分段参与排版与确认
- [x] 验收项 2：矩形空间行为与现状逐像素一致（回归）
- [x] 验收项 3：纯函数单测（裁剪模块）+ 专项 e2e

## 定稿语义（2026-10-23）

- `channelRects` 输出 = 包围盒钳制后再按 `zone.polygon` 单环裁剪的分段矩形集合；矩形空间输出与裁剪前逐值一致（扫描线只有一个分段且区间与禁放带完全重合）。无多边形数据退化为包围盒单矩形（旧行为）。
- `axisSegments` 排版切段**仍按未裁剪禁放带全轴切分**：桌列不允许跨越通道线，即使该段通道在部分走向范围落在房间外。裁剪只影响绘制、压占校验与避障阻挡。
- 「仅从二排起」先在走向上平移起点，再参与裁剪，语义不变。
- 服务端核验（LAYOUT-022）**无需改动**：被确认家具必须先完整落在房间轮廓内（先于通道检查拒绝越界），因此 `家具 ∩ 禁放带` 与 `家具 ∩ (禁放带 ∩ 房间)` 等价，前后端判定一致。

## 实现

- `utils/spatial/geometry.ts` 新增纯函数 `clipRectToRingRects(rect, ring, eps=0.5)`：扫描线按顶点 y 分段、段内奇偶规则求交并裁剪到矩形 x 范围、同跨度相邻段合并。轴对齐多边形精确；**斜边在顶点 y 处阶梯近似**（偏差 < eps 量级，属边界说明）。
- `layoutChannels.channelRects` 按上述语义输出多段；消费方均已按数组处理：`confirmedLayoutProblem`、officeAutoLayout 避障阻挡、画布渲染与吸附目标。
- 画布渲染：一条通道的多个分段各自可点选/拖动（同一 channelId）；标签与宽度拖柄挂在**面积最大的分段**上；拖动预览对各分段同量平移/伸缩，提交时重新裁剪。
- 边界：禁放区/入口区域的多边形裁剪未做（其语义与通道不同，留待单独评估）。
