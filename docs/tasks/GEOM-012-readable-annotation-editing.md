# GEOM-012 可读且可编辑的画布标注

状态：已实现并通过专项验证
更新日期：2026-10-24

## 目标与验收

针对单空间设计中标注随画布缩放到无法阅读、文字编辑入口未接入的问题，保持标注位置仍使用世界坐标，同时让便签和文字在屏幕上保持可读尺寸；支持双击和选中操作栏编辑，提供删除和撤销。

- 缩放只改变标注的世界尺寸补偿，屏幕字号和便签宽度保持稳定，不修改空间或家具几何。
- 双击标注或点击选中后的“编辑”可修改文字；支持完成、取消及失焦保存。
- 选中后可删除，Delete / Backspace 和撤销继续有效。
- 标注仍按 zoneId 归属当前空间，切换空间不串显示。
