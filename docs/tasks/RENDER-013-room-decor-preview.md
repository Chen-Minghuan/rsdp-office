# RENDER-013 房间装修预览

状态：本地试用版。

从「布局选品 → 3D 白模 → 装修预览」选择「浅灰商务」或「暖木自然」。两个预设使用同一份毫米场景。俯视隐藏前景墙，便于核对家具排布。人眼视角显示完整墙体、示意顶面和线性灯，只有找到可用取景点时才开放。

`planRoomDecor` 输出可序列化的装修指令，包含材质预设、墙上饰面、可选绿植、灯具和人眼镜头。Three.js 复用现有墙体、门窗和家具模型，再叠加装修效果。墙面饰件选无洞口的墙段。绿植按房间边界、家具占地、障碍物、门扇净空和布置区筛选，空间不足时省略。该检查用于预览，现场通行仍需复核。

装修模式只读，不写回排版、选品或方案。已在排版内的椅子保留，白模附带的示意配椅在装修模式隐藏。家具继续沿用现有模型解析，缺少对应模型时显示类别示意。模型工具调用、本地预览持久化和正式方案交付在本版范围之外。

验证：前端生产构建、白模和家具 3D 纯函数测试通过。Edge 以 1600×1000 窗口运行白模与 AI 效果图模拟回归。白模回归新增 20 桌示例，覆盖两种风格、俯视、人眼视角、装修期间禁止键盘改动和切回白模重新编辑。已目检俯视和人眼截图。本地隔离预览 3019 响应正常。示例按截图构图重建，使用示意尺寸和模型。
