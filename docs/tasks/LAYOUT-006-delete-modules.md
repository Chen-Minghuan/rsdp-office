# LAYOUT-006 单位模块删除

状态：已实现并通过专项验证
更新日期：2026-10-15
基线：当前工作区；保留自定义目录、逐件放置及自动多排改动。

## 目标与验收

选中当前空间中的家具实例后显示明确的“删除选中模块”按钮，Delete/Backspace 同步可用，删除可撤销并持久化；删掉一件后当前空间剩余家具的排版确认失效，其他空间及目录保留。

自定义目录的移除入口明确命名为“删除”，保留已摆实例快照，提供最近一次目录删除的独立撤销入口。内置图例不修改；目录删除与画布实例删除分开。

验证：按钮/快捷键删除、输入和弹窗防误删、撤销/刷新恢复、确认依赖、其他空间及目录保护、自定义删除/撤销和旧实例保留；构建与相关模拟回归。

## 实现与验证

- 画布右上显示所选家具名称和删除按钮；快捷键复用同一删除函数，验证对象属于当前可见空间，不删除隐藏的其他空间对象。
- store 删除找不到的 ID 不创建撤销记录。家具删除只移除该实例，取消其空间剩余家具的排版确认并清除 submitted，沿用 objectUpdate 的撤销、修订及保存；撤销后恢复原确认状态，状态提示同步消失。
- 自定义目录“移除”改为明确“删除”，保留旧家具快照；最近一次目录删除可独立恢复，同名冲突明确反馈，不覆盖已有定义。目录操作不修改几何或排版确认。
