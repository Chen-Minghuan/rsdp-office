# LAYOUT-048 家具重叠提示与定位

单空间排版画布沿用家具碰撞规则检查已摆家具及当前预览中实际显示的家具。遇到重叠时，两件家具描红，左上角列出冲突家具名称和当前画布顺序号。点「定位」将冲突对收入视野。调整位置后提示自动更新。数值间距不足与占地重叠分别提示，零净距贴边沿用排版允许规则。

后端保存、方案确认和效果图快照检查继续拦截重叠。返回的校验消息包含房间名、两件家具名和各自的画布坐标。

验证：Java 444 项，434 通过、10 跳过。前端构建、排版算法、效果图与预览拖动模拟回归通过。覆盖冲突名称、定位后两件家具高亮、零净距贴边后提示消失及确认家具与草稿家具相交。未在用户项目中修改排版。
