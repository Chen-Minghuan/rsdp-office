2026-10-15 规则更新：用户取消逐空间确认门槛。复核只提示、按需修改后直接排版，当前行为见 [FLOW-002](FLOW-002-advisory-space-review.md)。下文的逐空间确认描述/测试保留为此前实施记录。

更新日期：2026-10-15
依据：用户要求自动读取图中尺寸、校验比例，再由用户确认，减少手工两点校准。

## 范围与契约

- 识别空间时同时读取尺寸证据；已有记录可仅重读标准底图尺寸，不替换房间或编辑稿。优先由 Java 定位外围长直尺寸线并裁图，Qwen 转录该整段标注；不足两条定位候选时，使用完整标准图与四边放大图的模型端点回退。
- 来源端点使用同一标准底图坐标，后端换算像素长度、明确单位/单位假设、计算毫米比例。
- 比例候选与已确认比例分开。至少两条独立有效参考，采用 3% 相对偏差作为本轮初始一致性阈值（开发策略，非行业标准）；重复标注不计为独立证据，横纵向比例矛盾阻止自动应用。
- 无单位数字默认按 mm 形成候选，必须在确认面板明确展示假设，允许选择 mm/cm/m 后重新校验；不能静默视为可靠单位。
- 缺失、模糊、端点无效、单条参考、冲突不产生可直接应用的比例；保留手工校准。
- 用户确认时后端重新校验候选、analysisRevision、图像哈希与报告 ID；只接受服务端计算结果，不接受前端任意比例值。
- 应用只缩放当前设计副本和底图解释，不替换原始识别；全空间确认和关联排版失效。过期异步结果不得覆盖新来源或用户后续编辑。

## 验收与验证计划

- Java：不同图像长宽、单位转换/假设、重复/非法/低置信标注、单条/一致/异常值/横纵冲突，确认及过期报告检查。
- UI mock：候选出现但尺寸仍待确认；参考线对照、单位选择、确认后全图换算；冲突与失败保留手工校准；重新读取不丢编辑；刷新/撤销、异步过期保护。
- 前端构建、现有空间核对/上传回归、Java 测试、差异与文档检查。真实模型质量、数据库集成单独记录，不用模拟通过代替。

## 实施与验证

### 后端

- `DimensionLineLocator` 在标准底图外围 18% 区域寻找长于轴长 40% 的细直线，要求两端刻度，排除粗墙、边框和有中间刻度的分段链。横纵局部图统一旋转/放大，红点说明候选跨度；模型只返回 lineId 与逐字尺寸，不计算端点或比例。检测只是候选证据，不保证刻度已准确识别。
- 找不到足够长直线时，`VisionImagePreparer` 生成四边放大图；模型以 region 表示端点坐标，后端转换回同一标准底图。保存原始模型输出与规范化证据，未知 lineId/region 和越界端点不能参与比例估计。
- `DimensionScaleEstimator` 从文字和标准图像素跨度计算比例；至少两条、严格多数、3% 偏差策略，重复/过短/低置信/冲突参考不冒充可靠尺寸。横纵比例冲突阻止确认。
- `FloorPlanDimensionService` 将报告和确认依据增量保存在当前 revision 的 `raw_result`；数据库 JSONB 比较并交换且检查当前版本，避免异步结果覆盖新报告。没有新增表或改写原始 rooms/unitResolution。
- 三个接口为 `POST /api/v1/floor-plan/{id}/dimension-calibration/recognize`、`GET /api/v1/floor-plan/{id}/dimension-calibration`、`POST /api/v1/floor-plan/{id}/dimension-calibration/confirm`。读/识别使用 analysisRevision，GET 支持 assumedUnit；确认请求仅含 analysisRevision/reportId/assumedUnit。沿用项目业务错误响应约定（HTTP 200 的非 200 code）。

### 画布

- 右侧比例区域新增“图中尺寸自动校准”，展示候选、单位假设、采用/异常参考、最大偏差和所选空间面积预估。点标注在底图上对照端点；可切换 mm/cm/m 重新校验。
- “确认比例并应用到全部空间”先请求后端确认，再按候选绝对比例与当前来源比例的比值缩放设计稿，重复确认不累乘；原始轮廓和已有局部编辑保留。
- 应用、撤销/重做、本地刷新恢复纳入现有画布机制；全空间确认及关联排版失效，仍需逐空间复核。两点校准保留且清除自动依据。
- 候选读取/确认期间若来源、版本或设计稿变化，旧响应不能应用；读取失败不清空草稿。单位重验失败恢复上一次报告单位，允许重试。
- 已保存画布加载到同一来源时，补回底图与报告元数据并保存本地，保留设计编辑；新导入记录 sourceAnalysisRevision，同 ID 不同版本拒绝静默关联。无版本的历史稿只按初始 revision 1 恢复，不猜测新版本。

### 剩余边界

仅此一张真实 PNG 的尺寸候选完成实测，不代表 PDF/CAD 或房间轮廓质量已验收。模糊字、倾斜/弯曲尺寸、仅室内标注、分段标注、非等比拉伸仍可能需要人工校准；模型转录和端点检测均不是测量真值。完整 DesignScene 确认快照/跨设备恢复仍按 GEOM-001/FLOW-001 推进。
