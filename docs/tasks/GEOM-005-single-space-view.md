# GEOM-005 单空间设计隔离

状态：已实现并通过专项验证
更新日期：2026-10-15
基线：当前工作区；保留此前空间模板与校准改动。

## 目标与验收

用户从总览进入指定空间设计后，仅显示该空间真实多边形及归属家具；整层底图、其他房间和无归属参考内容留在总览。切换空间、刷新、适屏和视口尺寸变化后，当前房间正确居中；视图操作不修改几何和家具归属。

## 实现

- `canvasObjectsForView` 统一过滤渲染对象，无有效空间时返回空集合，不能回退显示全部家具。
- 按当前空间多边形范围建立视图，内容偏移、指针逆变换及适屏使用同一世界原点，支持负坐标和远离原点的 CAD 空间。
- 隐藏单空间中的整层底图与其他房间；新建标注/参考图记录 zoneId，仅展示当前空间归属内容。旧无归属内容保留数据、不混入单空间。
- 视口变化重新适屏，工具栏缩放同步实际变换；尺寸显示毫米，底部状态只显示当前空间。
- 仅视图隔离，不删除/平移原场景，不改变模板、阶段门禁或排版算法。
