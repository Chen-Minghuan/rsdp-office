## 目标与验收

2026-10-20 追加：用户重新提供四张明确参考图，T 型修正为 12 件、十字型修正为 16 件，C/T/十字镜像及职员台座席方向严格固定，新规则为 `2026-10-reference-v4`。后续现状以 [LAYOUT-015](LAYOUT-015-exact-reference-presets.md) 为准；下方早期 10/8 件记录保留为历史，不作为当前验收标准。

触发：在单空间排版中选择一字职员台、L 型职员台、一字屏风卡位或 L 型屏风卡位，再选择与产品样式兼容的排布模板。

结果：排版配置保存产品样式、排布模板和规则版本；素材中的默认间距进入可调整的模板初值；新界面只显示当前样式允许的图例排布；旧通用排版仍可读取。

范围：本阶段建立样式/模板契约并接入专用槽位规划器。规划器按图例生成单排、对坐及 F/T/C/十字的成组关系；T 型按成组单元横向分隔，C 型按围合单元横向分隔，十字型按十字单元纵向分隔，默认间距均取图示值。屏风共享线段和服务端完整校验仍需后续补齐。

- [x] 验收项 1：四类产品样式和素材中的排布模板可枚举，并按兼容样式筛选。
- [x] 验收项 2：一字职员台面对面默认 1600mm；L 型职员台单排参考 600mm；屏风 T/C/十字默认 900mm，均可调整。
- [x] 验收项 3：应用布局时保存 `productStyleId`、`arrangementPresetId` 和 `arrangementRuleVersion`，不覆盖旧布局兼容字段。
- [x] 验收项 4：样式专用槽位拓扑、方向和默认间距通过独立几何测试；屏风共享线段仍待后续补齐。
- [ ] 验收项 5：后端布局确认、商品匹配和效果图输入使用同一套样式快照。

## 现状与依赖

现有 `officeAutoLayout` 已支持自动多排、单排、背靠背、面对面、错位排、中间通道和沿边，`FurnitureObject.layoutSettings` 只有通用模式和间距。素材中的样式差异此前没有持久化字段，屏风和 L 型模块也没有独立的规则契约。

本阶段复用现有 `furnitureTemplateId`、`moduleSnapshot` 和毫米排版算法，保留旧 `gapMm/pairMm` 读取。后续专用几何需要扩展家具轮廓、座席锚点、屏风线段和共享构件数据。
