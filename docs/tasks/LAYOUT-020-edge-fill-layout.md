# LAYOUT-020 主排布之外的边缘余量单件补位

日期：2026-10-22。状态：已实现并通过专项验证，真实用户布局待核对。

## 用户反馈与目标

用户对比真实方案图指出：T 型对坐等排布只会平铺同一种完整单元，空间排不下或留有余量时不会像参考方案那样灵活调整（参考图为中央 T 型组团 + 两侧靠墙单排卡位的混合排版）。目标是在不破坏参考图拓扑的前提下，用主排布放不下的边缘余量。

## 当前实现（两阶段填充，方案 A）

- `planAdaptiveArrangement` 保持第一阶段不变：完整参考单元（对坐/T/C/十字整体保留或整体跳过）、横纵朝向与居中/贴边格网候选比较。
- 新增第二阶段 `edgeFillSlots`：主网格放好后，沿四面墙的余量条带逐件放置单件模块，屏风/面板侧贴墙、座位朝房间内侧（上墙 0°、下墙 180°、左墙 270°、右墙 90°），与主网格保持同一离墙距离、障碍净距和模块间距；被柱/门洞/保留家具遮挡的位置只跳过该件，不影响整条边。
- 补位参与候选评分，因此"较少主单元 + 两侧补位"的居中/旋转方案可以在总容量上反超贴边方案；排/列统计只计主网格。
- 指定目标人数时，完整单元优先，补位只补足差额；0 人表示尽量排满（含补位）。
- 完整单元横纵都放不下时，不再直接报死，而是降级为"沿墙单件补位"的可编辑起步方案。
- 补位件使用独立 `clusterId`（`:fill:` 前缀），不并入参考单元；方案标签追加"边缘补位 N 件"，全部补位时显示"沿墙单件补位 · N 件（完整排布单元无法容纳）"，并增加核对提示"主排布之外的边缘余量已用单件补位 N 件……请核对补位位置与现场通道"。
- 新规则版本 `2026-10-edge-fill-v7`；旧保存布局不变，需显式重新应用。超大空间（预计超过 2000 件）保持既有保护，不做补位。

## 边界

- 补位只沿包围盒四面墙条带生成；凹形空间凹口内侧、被跳过单元留下的内部空洞暂不补位，异形分区排版（方案 D）另行评估。
- 补位与主网格之间允许紧贴（gapMm=0，与参考图紧贴语义一致），未单独建模补位座位与主排座位之间的活动净距；门窗、柱和连续通道仍需现场核验，椅子为座席示意。
- 单一全局朝向的混合图案（不同区域不同排布样式）不在本任务范围。
