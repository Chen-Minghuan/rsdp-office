# GEOM-014 空间合并与剔除（轮廓布尔运算）

日期：2026-10-27。状态：已实现并通过构建及专项模拟回归；真实数据库持久化与用户业务验收待补充。

## 背景

对照目标画图工具条（上传 / AI 识图 / 拉框 / 异形 / 合并 / 剔除 / 删除 / 柱 / 门 / 窗 / 距离校正 / 布局边界 / 调整边界 / 删除边界 / 撤销），空间编辑缺「合并」「剔除」两个轮廓布尔操作（其余缺口见 [GEOM-015](GEOM-015-window-openings.md)、[GEOM-016](GEOM-016-layout-boundary.md)）。

## 目标与范围

空间核对总览工具条新增两个工具：

- **合并**：先点「要保留的空间」，再点「要并入的空间」。保留空间的轮廓变为两轮廓并集；被并入空间的家具、便签/箭头、障碍（保留稳定 ID、改挂归属）与选品清单改挂到保留空间，被并入空间删除。两侧空间确认、排版确认与已提交方案失效，模板需更新，全程一次撤销。
- **剔除**：先点「被裁剪的空间」，再点「用作剔除的空间」（该空间保持不动）。被裁剪空间轮廓变为差集；确认与排版失效，越界家具由既有排版校验提示，一次撤销。

## 取舍（定稿）

- 布尔引擎使用 `polygon-clipping` 依赖，不手写裁剪算法；纯函数封装在 `utils/spatial/boolean.ts`，输出做 0.01 精度取整、去重复端点并过 `ringProblem` 校验后才落库。
- `ZoneObject.polygon` 只支持单外环无孔洞。布尔结果为**多块分离**或**带孔洞**时拒绝并给出可操作提示，不静默取最大块、不悄悄丢孔：
  - 合并结果分离 → 「两空间不相连，合并后会分成多块，当前空间轮廓不支持」
  - 剔除后为空 → 「剔除后空间不剩任何区域」；剔除后分离 → 「剔除会把空间分成互不相连的多块」
  - 剔除产生孔洞（剔除区域完全在内部）→ 提示改用「禁放区」标注
- 仅空间对空间的布尔；不实现"画矩形剔除"。剔除的刀具空间保持不动（合并才会删空间）。
- 单位基准不一致（一个已校准一个未校准）拒绝操作；同为源单位或同为毫米可运算。

## 验收标准

1. 合并两相邻矩形得 L 形单环，家具/障碍/选品归属保留空间，确认失效，撤销完整恢复两个空间。
2. 剔除边界重叠区域后轮廓顶点正确，面积联动，确认失效，可撤销。
3. 上述拒绝分支逐条给出明确文案且不改动数据。
4. 纯函数测试（矩形/L 形并差、分离、孔洞、无交集）通过；`pnpm build`、`e2e:space-review`（含合并/剔除/撤销断言）、MOCK 冒烟、`git diff --check` 通过。

- 前段「画区旋转角度 90°」会在组件内残留，后续形状模块拖拽会带出 90° 旋转（浮点余弦使 100mm 取整出现 ±50 尾数）；本段每次画矩形前显式归零。
