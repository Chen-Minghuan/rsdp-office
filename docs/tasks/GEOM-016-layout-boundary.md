# GEOM-016 排版布局边界

日期：2026-10-27。状态：待开始。

## 背景

目标画图工具条含「布局边界 / 调整边界 / 删除边界」一组：在空间轮廓内正向圈定家具允许排布的范围。当前只有反向语义的禁放区障碍（NO_PLACEMENT）与通道禁放带，没有"排布有效区"对象；GEOM-007 轮廓自由变换调的是空间轮廓本身，不是独立布局边界。

## 目标（草案，启动时定稿）

- 空间可挂一个可选的布局边界多边形（正向约束）：自动排版只在边界内放置；无边界时保持现状（整个轮廓）。
- 工具条提供绘制（拉框/逐点）、调整（顶点/边编辑，复用轮廓编辑交互）、删除三个动作。
- 与禁放区/柱/门洞的关系定稿：布局边界与既有障碍取交集作为最终可排区域；增删改按依赖使确认/排版失效。
- 服务端核验同步语义（参照 LAYOUT-022 通道核验挂点）。

## 依赖

GEOM-011 障碍标注交互；LAYOUT-021 通道体系；GEOM-014 布尔运算可复用（边界与轮廓求交校验）。
