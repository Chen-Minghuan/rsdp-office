# GEOM-011 单空间建筑约束标注与避障

状态：已实现并通过构建、算法及 UI 模拟专项验证；真实业务集成待验收
更新日期：2026-10-21

## 目标与范围

在空间核对阶段放大单个空间，对照底图人工标注柱、门洞净空和禁放区；保存后进入家具排版，自动排版、逐件放置、拖动和确认共用同一批毫米约束。

本版提供柱/禁放区矩形和门洞净空四分之一圆扇形人工标注，不包含 CAD/PDF/PNG 自动障碍识别，也不把门洞净空伪装成已经识别的门窗实体。

## 实现

- 空间核对增加当前空间聚焦，只调整相机和可见空间，底图、障碍及轮廓继续使用原世界坐标；可返回全图。
- 聚焦后拖拽标柱、门洞净空或禁放区，红柱/蓝门洞区分语义；门洞从铰链角拖出四分之一圆扇形，可修改半径、切换四个开启方向，其他障碍可修改宽深，均支持删除和撤销。
- 已放置约束可再次选中并拖动移动；柱/禁放区通过四角手柄调整，门洞通过弧线手柄调整半径，也可继续使用上方数值编辑。操作期间使用独立草稿，取消/失败不改变已存几何，成功保存原位更新稳定 ID，不修改房间轮廓。
- 柱/井支持可开关的贴墙吸附：创建、移动、手柄和数值编辑时，按 `min(8 CSS px / 缩放, 20mm)` 阈值对齐所属空间的水平/垂直边；只处理与墙边范围相交的柱边，不吸附门洞、普通禁放区或斜边。
- `ZoneObject.obstacles` 使用 `SpatialObstacle` 毫米多边形并记录人工来源；场景适配、模板签名和模板副本保留障碍，不再在排版侧栏另建一套事实。
- 柱/井类实体占地按与房间轮廓的交集扣减净面积；门洞净空和普通禁放区只影响排版，不扣净面积。无效、越界或实体占地重叠会阻止精确排版。
- 自动排版、椅子活动区、逐件放置、手动移动和确认均读取建筑约束，同时兼容旧 `layoutPreferences.exclusions`；门洞按扇形多边形碰撞，不再按整个外接矩形禁放。
- 新增或修改约束沿用空间变更失效规则，保留旧家具但取消布局确认；后端独立拒绝已确认家具占用约束区域。
- 上一版已保存的四顶点矩形门洞在草稿加载时升级为朝室内开启的扇形，保留稳定 ID，只使对应空间的排版确认失效；可用“换向”继续校正。
- 效果预览快照保留障碍字段，物理布局上下文将障碍加入 reservedAreas；未重新调用收费生图。

## 限制与下一步

- 柱和普通禁放区当前只生成矩形，门洞使用 16 段近似四分之一圆弧；任意多边形障碍及其任意顶点编辑、真实门扇开启几何尚未实现。
- 贴墙吸附当前只支持所属空间的水平/垂直边；斜墙投影吸附、墙角双边联动和其他空间边缘吸附尚未实现。
- 未执行真实数据库保存/服务重启、用户原图业务验收或自动识别准确率验收。
- 后续可按 CAD 矢量、矢量 PDF、PNG 规则候选的顺序增加自动识别，候选仍需在空间核对中接受或排除。
