# 外部参考：培训空间自动布局工具（Kimi 原型 V1–V6）功能盘点与差距分析

> **性质声明**：本文是对外部参考原型（Kimi 分享会话 `1a1522f6-fd12-82c0-8000-000053a37f27`，纯前端演示工具）的**背景盘点**，不是本项目的目标契约；其中所有数值阈值（0.6m/0.9m/1.4m/2㎡/人等）均为该原型自定义的策略值，**非建筑规范证据**。哪些功能进入本项目、以什么语义进入，以对应任务卡的定稿为准。
> 整理日期：2026-10-26；来源为分享页会话文本（Playwright 渲染提取），该原型的《规则与算法说明》文档版本停留在 V4 引擎，V5/V6 新增规则无文档、以下 V5/V6 描述来自会话中的开发自述。

## 原型版本演进与功能清单

### V1（初版）
- 布局模式：课桌式（行列+通道列）、分组岛屿式（横/竖岛自动择优）、U 型/回字型（三边/四边坐人）。
- 求解模式：人数优先（自动配桌型桌数）、桌数优先（校核给定桌数能否放下）、最大容量。
- 候选枚举「桌型×朝向×通道列数」，按目标达成(55)+舒适度(30)+空间利用(15) 评分，Top3 方案卡片点击切换。
- 参数面板实时重算：房间宽/进深、讲台尺寸/对齐/距首排、门（所在墙/偏移/净宽，门前 1m 缓冲区落桌提示）、13 种桌型勾选、人均占宽、前后桌距(默认 1.0m)、左右桌距(默认 0.6m)、通道列数(自动/0/1/2)与宽度、侧墙/后墙留距、紧凑/标准/舒适三档预设。
- 校核预警：通道<0.6m 红、排距<0.8m 黄、人均面积不足、容量未达标、桌位侵入门缓冲区、岛间排距过窄，均附修改建议。
- 输出：线条示意图（缩放/平移/尺寸标注开关）、导出 PNG、导出 A4 PDF 布局说明、参数模板 JSON 导入导出（仅浏览器本地）。

### V2（五点反馈）
- 讲台可选任意墙，整个布局随讲台旋转；座位朝向规则：分组式只生成竖向岛屿（零背对讲台），回字型允许单边背对。
- 讲台/门沿墙画布拖动定位；门偏移钳制在墙长内。
- 通道对象化：纵向 ≤3 条、横向 ≤2 条，各自独立位置+宽度，画布虚线带拖动。
- 课桌式不再限制一列一通道：通道区段内自动多列并排。
- 椅子占用深度（0.48m）计入排布，椅子不再侵入通道带。

### V3（第四轮反馈）
- 宽桌双侧坐人：桌深 ≥1m 默认双侧坐人（人数翻倍），可开关；双侧坐人且前后桌距 <1.0m 时黄色校核。
- 参数面板按选配逻辑四步分组：① 空间大小与人数 → ② 留距 → ③ 桌型与布局 → ④ 通道。
- 门前预留默认 1.4m（可调至最低 0.4m；<1.4m 黄、<0.9m 红）。
- 回字型横竖排边缘对齐（不再只在边角相交）。
- 求解目标去掉，改为「空间人数」：按面积约 2㎡/人 自动推荐、可改、一键采用推荐值。

### V4（修复轮）
- 分组式双侧坐人生效；椅背对椅背强制 ≥0.5m 通行（岛间/岛内/课桌式排距自动加宽至 1.46m 并在校核提示中说明）。
- 紧凑/舒适预设失灵修复；排不出方案时画布中央显示兜底提示与调整建议。

### V5（三大功能）
- 靠墙增补座位：开关+多选墙（非讲台墙），沿墙按人均占宽排椅、避开讲台与门缓冲区；空间足够时可选二排加 0.4m 条桌（净深 ≥1.35m）。
- 剧院式：不要桌子（前排保留桌排数 0–4 可调、后排全椅子）；椅子可选联排（密排默认）或独立（左右/前后间距自定义）。
- 传统条桌产品类型：折叠培训桌｜传统条桌｜弧形会议 三选；主席台开关（讲台上/前排），主席台前挡板落地、导出清单与普通条桌分开统计。
- 弧形会议空间：弧形桌模块绕圆心排布（内半径 0.5–30m、桌深 0.4–1.2m、展开角 30–360°）；圆心默认对齐房间中心，可手动输入或画布拖动（可拖出房间外）；椅子始终面向圆心；斜向通道 = 过圆心楔形带（角度 −180°~180°、宽度 0.4–3m、≤4 条、手柄旋转/数值输入），带内桌椅自动剔除；座位避开讲台区/门缓冲/离墙 0.3m。

### V6（四大模式定型）
- 常规整桌会议空间：一张完整会议桌居中、两侧对坐、端头加座；桌宽 >2m 提示改用组合会议桌（拆两张 + 中间 0.3–1.5m 可调间隔，导出清单注明组合式）。
- 折叠培训会议空间：保持课桌式/分组式/回型三种布局。
- 木制条桌会议空间：主席台排数 0–4、条桌排数 0–8（其后为纯椅排）、讲台类型三选（讲台/大屏幕 2.0×0.8、演讲台 0.7×0.5、多功能讲台带电脑 1.4×0.7）；回型面对面间距可调；课桌式一二排间距独立；支持手动录入条桌尺寸。
- 弧形会议空间：阶梯直排扇形（3 或 4 区不同角度直排、全部朝向中心讲台）；弧形通道可拉通一排二排；「有椅必有桌」（桌排椅由桌模块生成）；「后几排仅椅子」0–6 排 /「仅礼堂椅·前几排配桌」0–6 排。
- 纵向通道「仅从二排起」勾选（首排不断开）。

| 原型功能 | RSDP 对应 |

### 未立卡、需业务确认
- **讲台/大屏幕概念**（任意墙、沿墙拖动、距首排、类型三选、座位朝向跟随讲台）：RSDP 是办公场景，座位朝向目前由排布模式决定；是否引入「朝向焦点」抽象需与需求方确认。
- **主席台/传统条桌产品类型**（挡板落地、导出分开统计）、**组合会议桌拆分**：属商品/产品线语义，涉及商品库字段与推荐匹配，不单独立排版卡。
- **阶梯直排扇形、仅礼堂椅**：已并入 LAYOUT-031 暂缓范围。

## 使用注意

1. 原型的所有校核数值为自定义策略值；本项目引入时沿用「策略提示、非规范强制」口径（LAYOUT-023/029 先例）。
2. 原型为纯前端演示：无持久化、无服务端核验、无真实商品绑定；对应能力在本项目必须走后端核验与失效规则（LAYOUT-022 先例）。
3. 原型会话中 V5/V6 的规则未补入其规则文档，本盘点的 V5/V6 描述以其开发自述为准，实现细节可能有出入。
