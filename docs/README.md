产品目标以用户最新明确要求为准，代码描述当前实现，进度表记录实现与验收的差距。
根目录原型设计和模块抽取文档保留为历史设计资料；与新目标不一致的内容不作为当前验收标准。
API 名称、字段与状态标为“目标”时，表示后续设计契约，不代表现有接口已支持。
